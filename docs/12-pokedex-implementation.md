# 图鉴实现与验收

2026-09-17。状态：可运行的跨平台图鉴核心、内容编译器、开发预览。尚未链接 GBA ROM；完整内容审定不是本轮已经完成的事项。

## 运行

在项目根目录 PowerShell：

```powershell
./tools/build_pokedex.ps1
node tests/pokedex-wasm.cjs
node tools/serve_pokedex.cjs
```

访问 http://127.0.0.1:4173 。服务器仅监听本机，端口可用 OMNI_DEX_PORT 设置。网页文件与数据可离线使用；在线参考像素图失败时显示占位说明，不影响查询。服务不接受写文件 API，也不暴露任意项目路径。

编译依赖 Zig 0.13.0（脚本支持 -Zig）、Node 与现有固定 Showdown 包。依赖安装方法见 `tools/legality-reference/README.md`。生成数据通过 SHA-256 固定本地 CSV 快照；网络下载时未取得 PokeAPI 提交 SHA，所以清楚记录 master 请求地址，不能称该下载是按提交固定。后续重建不访问网络。

## 平台分层

- `core/include/omni/pokedex.h`、`core/src/pokedex.c`：无 OS、渲染、文件、动态分配。支持 UTF-8 名称子串/英文大小写无关搜索、全国编号、类别、物种初登场世代、属性与收集进度筛选、分页、统计、独立形态登记、版本化进度保存与载入。
- `content/pokedex/generated/catalog.c`：从内容源编译的只读索引，ARM7TDMI 已可编译；核心不在 GBA 上解析 JSON。
- `adapters/headless/pokedex_wasm.c`：将同一份 C 核心暴露给浏览器。浏览器不重写筛选和登记规则；详细资料、布局及存储设备服务在宿主完成。
- `adapters/pokedex-preview/`：中文开发预览。默认列表含特殊形态，可单独筛选；参考与待核实资料有不同标签。手动登记仅用于验收，不能直接作为真实游戏的获得权限。

GBA 正式前端尚需字体编译、240×160 窗口/按键适配、精灵图与色板打包、游戏事件接入和持久存档事务。3D 前端可以复用核心接口和内容身份，展示自行实现。

## 内容编译与边界

`tools/legality-reference/import-localization.cjs` 验证研究快照哈希，并导出 1,025 物种中文名、特性和招式名称。`build-pokedex.cjs` 生成：

- `catalog.json`：展示资料与招式参考池。
- `generated/catalog.c` 与 `.h`：核心索引只读表。
- `coverage.json`：实际覆盖数量和缺口。

当前共 2,153 个可浏览条目，其中 2,080 个参考条目可验证登记功能，73 个待核实条目只读。数量包括 661 个基础物种极巨化状态条目，不等于 2,153 种宝可梦，更不是已审核的官方全形态数量。97 条 Mega 记录里包含上游标为 Future 的待审资料，不能宣传为已验证的 97 个官方 Mega。

分类：基础 1,025、极巨化状态 661、Mega 97、超极巨化 32、地区形态 61、其他形态 193、外观形态 52、原始回归 2、究极爆发 1、太晶相关 6、火箭队羁绊候选 23。

极巨化资格以官方剑盾机制说明为范围，按固定社区第八世代收录表交叉核对；不在该范围的候选不再生成。保留条目附官方规则链接，但并未全部获得逐物种官方证明。地区形态/其他稳定形态对应的极巨化状态尚未全部生成；霜奶仙糖饰等外观组合不算已穷举。Future/Custom 是上游标记，不作为当前发布日期的事实判定；独立核实之前不展示猜测数值。

招式来源保留世代/学习方式编码、前置进化和基础形态来源，页面明确这是参考并集，不能当作当前游戏可同时使用的完整配招。剧情捕捉门槛未配置的内容不得从图鉴直接放行到战斗。所有 battle_data_approved 为 false，图鉴可登记与对战合法性审批分别管理。

火箭队 23 条候选可查阅、可检索，不展示猜测种族值与图像；完整 2.1 名单、素材和规则仍需核实。部分形态后缀与进化道具名称保留英文，中文基础物种、属性、常规特性和招式名称已经覆盖。

## 保存格式与事件

见过=1，登记=2，解锁=4；后续状态包含前置状态。每个 entry_id 独立，登记 Mega 不自动登记普通形态。宿主必须提交可信的战斗/捕捉/剧情事件；核心不根据用户界面按钮判断真实获得条件。

保存格式 ODEX v1 使用显式小端编码：12 字节头部、每个有进度条目 4 字节稳定 ID+1 字节标志、4 字节校验。空进度 16 字节；当前 2,080 个可登记条目全登记为 10,416 字节。RAM 进度每条 1 字节，目前 2,153 字节。保存只包含进度，不包含整只宝可梦或捕捉资格。

稳定数值 ID 由完整符号 ID 的 FNV-1a 生成，构建期拒绝碰撞。载入先验证版本、长度、校验、标志与重复 ID，再写入；失败不修改状态。目录重排不影响记录，已移除条目忽略，新条目初始化为零。该迁移仅适用于符号 ID 未改名，改名须单独提供迁移表。校验用于损坏检测，不是防伪签名。GBA 掉电安全仍由宿主双槽/日志存储实现。

## 本轮验证

- C 原生场景：中文/英文搜索、组合筛选、分页、独立 Mega 登记、候选禁止登记、保存容量不足不写入、损坏/截断不覆盖、目录重排增删迁移。
- ARM7TDMI/Thumb：同源核心与完整索引表编译为对象文件。
- Wasm：逐条核对全部 ID；逐类别与属性对照数据目录结果；登记、研究门槛和损坏记录恢复。
- Playwright/Edge：1440、820、390、320 宽度实际渲染，无横向溢出；中文搜索、Mega 独立登记与刷新保持、候选只读、空结果、错误导入保持原记录、键盘焦点、离线图像占位、数据失败与重试。截图在 `build/pokedex/`。

未宣称完成：真机耗时/RAM峰值测量、屏幕阅读器人工测试、完整 WCAG 审计、正式 ROM 图鉴画面、全部形态素材和全世界获取路线。网页浏览器渲染验证不代替这些验收。
