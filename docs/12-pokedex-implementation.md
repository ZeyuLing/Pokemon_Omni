# 图鉴实现与验收

核对日期：2026-09-18。当前交付为完整参考目录、可复用 C 图鉴核心和中文预览。固定 PokeAPI 形态表及本次官方图鉴快照均已逐条对账；不等于所有资料已获官方数值认证，也不等于已制作完可玩 GBA ROM。

## 运行与复现

```powershell
./tools/build_pokedex.ps1
node tools/serve_pokedex.cjs
# 另一个终端，服务器启动后：
node tests/pokedex-preview.cjs
```

访问 http://127.0.0.1:4173 。依赖为 Zig 0.13.0、Node、tools/legality-reference 的固定依赖；浏览器验收另需 Playwright 与 Edge。编译器路径支持 -Zig 参数，测试库路径支持 OMNI_PLAYWRIGHT_PATH。构建离线读取已提交快照，不运行在线下载器。服务器仅监听本机，可用 OMNI_DEX_PORT 指定端口；远程图片失败有占位提示。

## 来源与审计

- research/catalog-sources/manifest.json：16 个 PokeAPI CSV，固定提交 5c776e225f2150862e021062d7f304c8958368cc，逐文件 SHA-256 与字节数；包含名称、形态、数值、属性、特性、进化条件和道具。
- form-source-audit.json：1,579 条源形态记录全部有去向；1,536 条独立记录六项种族值和属性交叉一致。极巨化沿用来源形态数值，不充作再次独立验证。
- official-zukan-reference.json / official-zukan-audit.json：日本官方公开图鉴 1,302 条记录全部映射到目录或性别外观元数据，无遗漏。1,025 基础物种均有官方身份链接，283 特殊形态记录有官方身份依据。官方图鉴的能力图表不能当成精确种族值。
- official-form-evidence.json：97 条 Mega 和 34 条超极巨化的官方页面依据。某些性别细分只有形态家族依据，页面区分证据范围。
- champions-ability-reference.json：M-C 五条 Mega 特性，固定 Showdown 提交 2ddfa0476f8207e12e204b1c69f7c7683b17633c。修正旧 npm 包的临时适配值，包括 Mega 烈咬陆鲨 Z 的飘浮、Mega 路卡利欧 Z 的 Aura Guard。无可靠中文来源的新特性保留英文。
- form-art-reference.json / art-availability.json：固定 api-data 与 sprites 提交，保存 1,579 条图片元数据及 1,530 个不同正面 URL 的成功 HEAD 检查。网络参考图片不是可直接发行的 GBA 素材。
- content/bond/author-reference.json：作者发布包 Fuertes Vínculo.txt 的事实摘录，保留归档／文档哈希；不提交 ROM 或文档全文。

特性源之间的差异按“个体限制／版本集合拆分”和“缺少第二来源”分别记录，数量见 coverage.json。霸主、换装皮卡丘、达摩状态与物种特性集合不同；甲贺忍蛙、岩狗狗、基格尔德的特殊特性个体在不同源中拆分不同。页面解释原因，不把参考集合直接当作个体合法性白名单。

## 羁绊与实际缺口

23 条羁绊的名称、属性、特性、六项数值已从作者文档提取。文档无明确 2.1 标记，不能声称已确认“2.1 版本全部形态”。超甲狂犀原文总和 670 而六项合计 660，蚊香泳士原文 635 而合计 655；象牙猪数值行使用 M 后缀但位于羁绊章节。保留原始六项数值、原文总和及疑点。

尚缺精确版本对应、专属招式表、触发／解除条件及专属图片。Dun 是作者自定义物种，不冒用土龙节节全国编号。羁绊保持只读，直到本项目规则和来源审定完成。

参考图片链接覆盖 2,349 条，其中 2,348 条引用的正面 URL 已 HEAD 验证，另有官方基格尔德 Mega 图片。12 个普通特殊形态缺少专属图：故勒顿／密勒顿 8 个骑乘或休息状态、厄诡椪 4 个太晶状态；此外 23 条羁绊未导入作者图。后备图片不计为已验证专属图，实际缺口在 gaps.json。

世界获取地点、剧情门槛、改造后的羁绊规则及正式 GBA 图形需对应系统制作，不填虚构内容。招式池保留跨世代学习来源，不能代替四招同时合法性验证。

## 核心与存档

core/include/omni/pokedex.h 和 core/src/pokedex.c 不依赖 OS、渲染、文件或动态分配。支持中英文查询、编号／类别／物种世代／属性／进度筛选、分页、登记与保存。OmniDexProfile 提供六项数值、四特性槽、属性及转换父 ID，内容编译为只读 C 表。普通极巨化 HP 由 battle_stats.c 计算。

adapters/headless/pokedex_wasm.c 将同源核心暴露给预览；页面负责布局、图片和宿主存储。未来 GBA、3D 前端复用同一身份与核心接口。GBA 字体、240×160 布局、图形／色板、事件接入和存档事务尚需制作；GBA 不解析展示 JSON。

ODEX v1 显式小端：12 字节头、每条 4 字节稳定 ID + 1 字节状态、4 字节校验。空记录 16 字节；2,361 可登记条目全登记为 11,821 字节。进度数组 2,384 字节，不含应用其他 RAM。原 2,153 条符号及数值 ID 全部保留，新增 231 条不改变旧记录对应关系。

载入先验证版本、长度、校验、标志及重复 ID，再写入；失败不改变状态。目录重排／增删可迁移，ID 改名需另行迁移。校验用于损坏检测，不是反作弊签名。正式 GBA 掉电保护仍由宿主双槽／日志实现。

## 验收

- 内容：完整源清单对账、旧 ID、六项种族值／属性、中文形态名、转换链接、作者矛盾、近期特性修正。
- 原生 C：查询／筛选、独立登记、只读门槛、保存边界、损坏／截断原子性、目录迁移、Profile 参数和查找。
- Wasm：全部 ID、六项数值、四特性槽、转换父 ID 与 JSON 逐项一致；全部类别／属性筛选、HP、保存。
- ARM7TDMI/Thumb：同源核心和完整表编译成功；**对象文件不是已链接 ROM 或真机测试**。
- Edge / Playwright：1440、820、390、320 像素实际渲染，中文搜索、独立登记／刷新、错误导入、键盘、空结果、图片失败、加载失败重试、图片变体、63 组合形态导航、作者矛盾、未来公告区；无脚本错误和横向溢出。
- 既有战斗／合法性核心 60,392 项检查和项目骨架验证通过。
