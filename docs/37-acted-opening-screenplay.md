# 《未竟的和平》连续场景剧本

版本：2026-09-27.2。游戏脚本：`content/opening/prologue.json`。开场战争由 `content/opening/battlefield.json` 的共享 C 地图事件驱动；人物及招式不是背景图片。首次战争段约 51.5 秒（不手动推进对白）。

## 0. 大战末期 · 烟囱山多地区混战

出场：关都指挥官渡、丰缘指挥官源治、神奥指挥官大叶、合众指挥官嘉德丽雅，以及各自的训练家和地区特色宝可梦。场内 40 个实例全部有登记。军事身份、参战和军服属于 Omni 原创开场稿，原作没有这场战争。

*火山灰落在岩台上，裂谷中熔岩翻涌。镜头沿阵线进入战场。关都快龙与丰缘暴飞龙在上空交锋；地面的尼多王、喷火驼和波士可多拉施招。镜头继续向下，神奥烈焰猴、伦琴猫、烈咬陆鲨与合众哥德小姐、劈斩司令、龙头地鼠加入交战。各队目标交错，不是两种颜色的镜像部队。*

**渡：关都突击队，压上去！快龙，打穿前面的阵线！**

**源治：丰缘守军，稳住！暴飞龙，截住空中的快龙！**

**大叶：神奥队，别挤进裂谷！烈焰猴，掩护侧翼！**

**嘉德丽雅：合众队，散开！哥德小姐，挡住侧面的攻击！**

*余下数秒交战后黑场一秒，切至同一地点稍后。岩台上的烧痕和倒地单位保留在原来的位置。16 只宝可梦与 4 名训练家停止行动；8 只宝可梦仍在残阵中交战。没有宣布停火、胜负或个体死亡。镜头靠近一名守着喷火驼的丰缘训练家，背景中的招式仍在飞过。*

**丰缘训练家：喷火驼，你醒一醒！求你了……看看我啊！**

*镜头移到神奥阵地。一名训练家蹲在倒下的伙伴身边；救护人员沿可通行的岩台接近。*

**神奥训练家：别睡！你听得见我吗？我们还没有回家……**

**关都训练家：救护队！这里还有人！别再往这边打了！**

**源治：先把伤者带下去！还能动的，掩护救护队！**

**渡：把伤情送回联盟。这里还没有停火。**

*伤情命令接入稍后的联盟会议，省略返程时间。年份、具体日期、这场战役的最终结果及战争结束过程均留空。此段不是早年的红莲事件。哭喊用对话框演出，未制作人物配音。*

细节、素材与验证见 [火山战争导演稿](40-volcanic-war-direction.md)。

## 1. 关都联盟 · 议事室

前线来讯切入议事室，联络官走到桌旁呈交伤情报告。

出场／剧内声音：渡、联盟联络官。

*联盟联络官沿来源地图的通道走至下一站位；绕开桌椅、设备、花盆和其他演员。*

**联络官：前线刚送回伤情。各地中心的药品都在告急。**

**渡：伤情册留下。另一份，念。**

**联络官：世界赛提案。每四年一次，以赛代战。**

**联络官：冠军执掌世界联盟，前四名参与行政。**

**渡：参赛资格？**

**联络官：须有担任或击败地区天王、冠军的记录。**

**渡：我会参赛。**

**联络官：但关都希望，冠军始终服从本地区的决定。**

*人物停顿，没有立刻作答。*

**渡：各地区还各发各的命令，战争就不会结束。**

**联络官：那下一代的人选，还要继续筛吗？**

**渡：继续。我要他们也能走到最后。**

**联络官：这批年轻人，连徽章都还没集齐。**

**渡：现在没有资格，不等于将来没有。**

## 2. 希尔弗 · 会客议事室

由尚未取得资格的年轻人名单，切到商界正在评估的另一份候选档案；同一首音乐延续，不暗示两方秘密合作。

出场／剧内声音：希尔弗家族代表、希尔弗秘书。

*希尔弗秘书沿来源地图的通道走至下一站位；绕开桌椅、设备、花盆和其他演员。*

**秘书：还没拿齐徽章，就给这么多赞助？**

**家族代表：等他们成了冠军，还轮得到我们开价？**

**秘书：账目可撑不起每个人。**

**家族代表：商店、中心、百货大楼。关都之外呢？**

**秘书：各地区的准入，都还得重新谈。**

**家族代表：所以看清楚，谁能替我们打开那扇门。**

**秘书：只押一个人？**

**家族代表：四个席位。为什么只盯着一个？**

**家族代表：还有，先查身份。战绩好，不代表能入场。**

## 4. 真新镇 · 大木研究所

从为年轻人安排道路，转到小茂自己追问明天的起点；先呈现祖孙会面，待小茂离开后才留下独处研究的悬念。

**小茂：爷爷，我明天能自己选伙伴吧？**

*小茂沿来源地图的通道走至下一站位；绕开桌椅、设备、花盆和其他演员。*

*大木博士沿来源地图的通道走至下一站位；绕开桌椅、设备、花盆和其他演员。*

**大木：当然。伙伴总要你自己选。**

**小茂：可世界赛连报名，都要先赢过天王。**

**大木：先去拿八枚徽章。别急着替明天的自己下结论。**

**小茂：那小智呢？您也会这样告诉他？**

**大木：他也有自己的路。**

**小茂：好。明早见！可别又熬夜了。**

*小茂沿来源地图的通道走至下一站位；绕开桌椅、设备、花盆和其他演员。*

*大木博士沿来源地图的通道走至下一站位；绕开桌椅、设备、花盆和其他演员。*

*大木独处，研究终端亮起。*

**屏幕：对战推演：胜利。是否继续测试？**

*大木独处，研究终端熄灭。*

## 5. 翌晨 · 真新镇

研究所熄屏后的黑场只承担一夜流逝；清晨镜头移向小智家，母子声音由屋内传出，接经典迟到开局。

出场／剧内声音：花子、小智。

**花子：小智！已经几点了！**

**小智：糟了！我的第一只宝可梦！**

## 舞台与实现边界

联盟议事室使用火红 SilphCo_6F 的会议桌房间作为场景适配，希尔弗使用 SilphCo_11F，会内火箭队使用 RocketHideout_B1F 的桌案区域。没有把这些素材的源地图名称当作 Omni 的世界地理或组织历史。

碰撞来自源地图 blockdata 与 metatile 行为属性，前景遮罩只负责遮挡。编译时检查站位和目标，以其他角色的占位规划四方向路线；共享 C 层逐像素检查脚下区域，路线异常时停在最后安全位置。

本轮只更换开场对话排版，未宣称所有其他菜单和普通探索对白已经完整复刻。过场人物采用已登记的现成火红小人；完整年龄皮肤和最终动画设计仍是后续工作。
