# 《未竟的和平》连续场景剧本

版本：2026-09-26.9。游戏脚本：`content/opening/prologue.json`。六场、77 个节拍；A 显示全文／继续，走动和建立战场的镜头自行完成。

开场先让玩家看见战争：河谷中大批宝可梦在空中、水面和地面混战，援军请求无法得到满足。前线要求上报伤情，镜头才进入收到汇总的联盟议事室。世界赛提案因此承接结束战争的需要，同时把权力交给胜者。各方手里的文件是各自取得的提案副本和候选资料，不是同一名信使串联各方，也不暗示他们已合作。各场只推进当前的决定，不罗列几十年历史。

日期仍为空；时代只定为第一次世界大战末期。匿名角色有独立档案，未知生平保持留白。玩家看不见小智的 AI 身份、研发标签或测试对象；小茂离开以后，大木才打开研究终端。

## 场景之间的连续性

0. 六秒无旁白、无对白窗的战场建立镜头，横移扫过水陆空宝可梦混战。随后两句前线无线电报告，让增援压力落到具体情境；“把伤情报回联盟”衔接会议桌上的报告。
1. 议事室里先放下伤情汇总，再读世界赛提案。渡从参赛门槛问到下一代，结束在“现在没有资格，不等于将来没有”。
2. 切到希尔弗的另一份年轻人资料，秘书紧接着质疑“还没拿齐徽章，就给这么多赞助？”双方谈出席位与市场的关系，以身份审查结束。
3. 切到火箭队的资格文件：坂木有冠军战绩，却没有合法身份。绕桌靠近成员的动作发生在这个打击之后。他要求继续神兽调查与年轻人培养，最终说到选择的机会。
4. 小茂在门口问“我明天能自己选伙伴吧？”把被安排的下一代变成有自己诉求的人。祖孙谈伙伴、徽章和小智，小茂先离开；同一机位留下大木，再开屏，玩家此时才看见推演。
5. 唯一承载明显时间省略的黑场从研究所熄屏进入翌晨。花子的声音来自小智家，接回经典迟到开局。

战场先用来源《训练家对战》配乐，前线要求上报伤情时转《希尔弗公司》，连续进入三场会议及祖孙会面，换房间不重启曲目。大木独处开始研究时转《大木研究所》，翌晨转《真新镇》。战场不显示场景说明牌，以免遮挡混战；会议室说明牌只在建立场景的动作节拍短暂出现。对白统一使用来源的双行对话窗。

## 舞台与实现边界

联盟议事室使用火红 SilphCo_6F 的会议桌房间作为场景适配，希尔弗使用 SilphCo_11F，会内火箭队使用 RocketHideout_B1F 的桌案区域。没有把这些素材的源地图名称当作 Omni 的世界地理或组织历史。

碰撞来自源地图 blockdata 与 metatile 行为属性，前景遮罩只负责遮挡。编译时检查站位和目标，以其他角色的占位规划四方向路线；共享 C 层逐像素检查脚下区域，路线异常时停在最后安全位置。

本轮只更换开场对话排版，未宣称所有其他菜单和普通探索对白已经完整复刻。过场人物采用已登记的现成火红小人；完整年龄皮肤和最终动画设计仍是后续工作。
