# 小智各时期外观设计 v0.1

2026-09-21。当前交付为可执行的美术规格与资产清单，**尚无成功生成的概念图和可替换像素皮肤**。游戏当前仍使用赤红地图像素占位，不把它标记为完成的小智外观。

沿用用户已确认方向：少年小智从真新镇起步，后续跨多年进入青年阶段。熟悉的轮廓与颜色保留，人物思想、经历和行为由 Omni 独立世界线塑造。年龄是本项目暂定设计，不宣称动画官方给出成年小智的这些造型。

## 三个阶段

| 阶段与稳定 ID | 暂定年龄 | 外观重点 | 动作与神态 |
|---|---|---|---|
| 启程 `ash.kanto.young` | 10–12 | 红白帽、蓝色短马甲、白短袖、绿色露指手套、牛仔裤、旅行背包；帽形、鬓角、面颊特征优先保留 | 步幅轻快、投球动作大；自信中带急躁，不画成冷酷成年人 |
| 历练 `ash.travel.adolescent` | 15–17 | 沿用红白帽和蓝白配色，外套更合身，装备更实用，帽檐和背包出现有限磨损 | 站姿稳定、观察先于出手；受挫表情收敛，仍有熟悉的笑容 |
| 青年 `ash.crisis.young_adult` | 21–23 | 蓝色短款旅行夹克、深色内搭和长裤，保留旧帽或其标识；不默认军装、披风、满身徽章 | 肩背成熟但不夸张健壮；面对伙伴放松，面对组织谈判克制 |

过渡通过明确的剧情时间跳跃解锁，不以宝可梦等级或随便一次读档触发。第一周目先用少年外观；后续周目与时间跨度仍可调整。外观解锁与剧情年龄应分开存储：通关后可以允许换旧衣服，但衣服不改变人物年龄、NPC 身份判断或剧情资格。运行时年龄与衣柜尚未接入。

推荐基础色（设计提案）：帽红 `#D84A48`、衣白 `#F3ECD8`、主蓝 `#3773B7`、深色 `#202B38`、手套绿 `#4F8A62`。三个阶段靠轮廓、比例和装备区别，不能只换色。GBA 实际调色板要在浅草地、深洞窟和中心地板上分别检查。

## 每阶段需交付的资产

1. 原画：正、侧、背全身视图，正面表情组，帽子与背包细节；各阶段统一比例尺方便比较。头、帽、手、脚不能裁切。
2. GBA 地图：当前适配器为 16×32 单帧，下／上／左站立各一帧，下／上／左行走各两帧，共九帧，右向镜像。先验证这套九帧，再扩展跑步、骑车、冲浪、钓鱼、投球；大幅非对称物件若不能镜像，需新增适配能力。
3. 战斗训练家图：正面与背面分别设计，建议先试 64×64 可读性；实际动作和预算核定后锁定尺寸。没有制作完成前不替换为缩小的概念图。
4. 菜单肖像：与同阶段地图轮廓、帽形、发型保持一致；表情不能偷偷改变服装。
5. 未来 3D：服装层次、材质、背包连接方式、帽子摘戴和前后结构明确；同一人物阶段 ID 映射模型，剧情核心不持有模型文件、纹理或像素坐标。

验收：240×160 原分辨率可分辨面向；走路脚步连续、不抖帽沿；深浅背景可辨轮廓；像素透明边无底色；各年龄有体态差异且始终可辨为同一角色。原画通过仅表示设计成立，不能算作 GBA 帧表或 3D 模型通过。
