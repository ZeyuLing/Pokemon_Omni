# 小智跨年外观设计 v0.3

2026-09-26。身体规则分为两段：获得真正肉身前不会长大，其余如常人；后续神兽受到小智打动，赋予肉身后可自然成长。全作跨少年、青年和中年，转变及各阶段年龄、年份、篇章仍未定。见 [肉身与成长方向](34-ash-human-body-arc.md)。

当前是设计方向和资产清单，尚无成功生成的小智概念图或可替换像素皮肤。运行时仍是赤红地图像素占位。

## 身体阶段与服装分开

动画小智的黑发、面颊标记、帽形及脸部特征作为贯穿年龄阶段的辨识基础。现有参考图是后期动画服装；开场初代服装仍需核对。青年和中年形象属于 Omni 对动画设计的年龄改编，不标为官方已经存在的成年立绘。

获得肉身之前只能改变服装、装备磨损和神态，不能因周目、等级或换衣操作长大。获得肉身之后可以随故事时间自然成长，不在转变瞬间自动跳到青年或中年。其他普通人仍按自己的时间成长。

| 阶段 | 稳定 ID | 当前状态 |
|---|---|---|
| 转变前少年外观 | `ash.kanto.young` | 保留；帽形与蓝白衣装为初代方向，像素尚未完成 |
| 获得肉身后的少年 | `ash.human.youth` | 方向已定；转变时具体体态、年龄和衣着未定 |
| 青年小智 | `ash.human.young_adult` | 方向已定；形象、年龄范围、经历与解锁篇章未创作 |
| 中年小智 | `ash.human.middle_aged` | 方向已定；形象、年龄范围、经历与解锁篇章未创作 |

后面三个阶段都以“已获得肉身”为必要前提，具体启用还取决于将来写出的故事时间。旧 `ash.travel.adolescent`、`ash.crisis.young_adult` 的固定年龄、服装和章节设想保留为历史记录，不自动复用。

## 后续资产制作要求

- 每阶段分别提供正、侧、背全身和表情组；每套衣装与对应身体阶段匹配，保留小智的连续辨识度。
- GBA 仍按当前 16×32 地图帧与九帧基础动作适配，后续动作另验收；不以概念图缩小代替帧表。
- 对战正背面、菜单肖像与地图角色使用相符年龄、帽形和衣着。
- 未来 3D 的身体阶段、服装与模型资源分开；共享 C 剧情核决定状态，平台负责呈现。

所有数字年龄、年份、身高、婚育关系和中年结局保持空白。本轮只记录方向，没有调用图像生成或更换游戏资产。
