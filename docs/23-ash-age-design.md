# 小智跨年外观设计 v0.2

2026-09-26。用户确认小智不会长大，除此之外与正常人没有区别。旧 15–17／21–23 岁成年体型提案撤销；少年轮廓作为持续身体基线，不是生物出生年或启用时间。见 [AI 训练家设定](33-ash-ai-design.md)。

当前只有设计规格，尚无成功生成的小智概念图或可替换像素皮肤。运行时仍是赤红地图像素占位，不能标记为最终小智资产。

## 当前形象规则

沿用动画小智的黑发、面颊标记、帽形和少年身材。现有参考图为后期动画服装，开场初代服装仍需逐项核对。跨年时可以改变衣着、装备磨损、动作习惯和表情；不自动加身高、成年肩宽、胡须或成年面部比例。

“不会长大”是 Omni 的身体设定，不是动画官方对小智年龄的解释。其他普通角色仍然随时间成长。外观保持少年不阻止小智积累经历；不得用衣柜切换改变剧情年龄、认知状态或报名资格。

## 每套服装的制作交付

1. 正、侧、背全身原画和表情组；各套保持相同身体比例，帽子、手、脚完整。
2. GBA 地图：当前适配器使用 16×32 单帧、九帧基础站立与行走、右向镜像。跑步、骑车、冲浪等另行扩展，不以概念图缩小代替帧表。
3. 战斗正背面、菜单肖像与地图角色使用一致帽形、发型和衣着；尺寸按运行时预算验证。
4. 未来 3D 保持同一角色与服装 ID；模型、材质和动作放适配器，不进入共享剧情逻辑。

验收仍在 240×160 原分辨率进行：方向明确、步态连续、透明边干净、深浅背景均可辨认；不同服装不改变身体成长状态。原画完成不代表像素动作或 3D 资产完成。
