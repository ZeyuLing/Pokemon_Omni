# 使用来源 ROM 素材重做游戏界面

2026-09-21。纠正上一版以纯色背景、矩形框和大字作为正式战斗／背包展示的问题。此次直接解码用户归档的西班牙火箭队 ROM，使用其界面像素、图块排列与调色板，在实际 GBA ROM 中绘制实时内容。

## 已替换的内容

- 草地和室内战斗场景：保留源背景的横向渐变、地面平台与透视构图；根据野战／室内训练师战选择背景。
- 双方状态框：使用来源像素框，实时显示名称、等级、HP、麻痹与玩家经验条；动态血条按当前 HP 绘制，不把整张静态截图当作游戏界面。
- 底部三类框：提示框、四项指令框、招式／PP 分栏框均来自原始战斗 tilemap。恢复“战斗、背包、宝可梦、逃跑”选择，进入招式后可以返回。
- 背包：原有左右分栏底图、绿色背包的三个口袋帧、伤药／精灵球图标与各自调色板。道具、精灵球、重要物品三个口袋显示实际库存；包裹交还后从重要物品袋消失。
- 通用对话和选择面板：使用来源窗口九宫格边框；文字使用已有 12 像素中文字库和紧凑数字，减少原来 16 像素大字导致的拥挤。
- 战斗中的换人列表提供明确选人；HP 从当前战斗对象读取，不展示入战前的旧 HP。原有 L 投球、R 快速轮换仍保留作快捷操作。

队伍详情、训练家卡片、商店和标题的完整构图还没有替换成来源游戏的对应界面；它们使用现有结构及统一文字／窗口样式。地图主角仍是占位像素。此次不声称全游戏美术、动画或音效已完成，也未扩大共享战斗引擎的物种／招式覆盖。

## 来源与复现

输入为 `assets/imported/rocket-user/rocket-user-modifier.gba`，SHA-256 `033235cdd389c4c8cb1aa6d68a93954a55fd681c92a1a554ebc63431117b4eaf`。本次使用这一份来源的视觉套件，未混称为究极绿宝石 5.8 的 UI。

定位时以 pret/pokeemerald 的 `5eff78649e7170a877b961ef0b3da13b81a16038` 为结构参考，将 PNG 按上游图块顺序编码，与两份用户 ROM 的解压内容比对。多项界面框、背包背景和道具图在两份 ROM 中均存在相同内容；最终构建只读取火箭队 ROM。草地和室内背景则从火箭队自己的场景表及对应调色板读取，不用上游默认配色覆盖。

另外在 mGBA 中载入来源 ROM，以普通菜单按键实际打开背包作视觉对照，确认紫蓝横纹、绿色背包、淡黄色列表和左下说明框确为该版本的背包配色与结构。参考截图保存在本地 `.cache/rocket-bag-reference.png`；本作的道具、数量、正文和操作仍由自身运行时绘制。

源 ROM 场景表位置为 `0x5a6368`，每项五个指针。单打信息框必须按 64×64／64×32 分块顺序重排。战斗 tilemap 的提示、指令与招式布局分别在 y=112、272、432 处，按 240×48 提取；没有凭感觉临摹原边框。当前共有 26 个来源数据块，组合为 16 个 GBA 适配资源，308,736 字节。

`assets/source/game-ui.json` 保存 ROM 身份、每块偏移、编码、压缩前后哈希、输出尺寸与像素哈希。`tools/build_game_ui_assets.py` 锁定完整 ROM 哈希，随后检查各块记录；输入错误会停止，不静默退回临时色块。

```powershell
./tools/build_pallet.ps1
node tests/pallet-smoke.cjs
python -X utf8 tests/test_game_ui.py
node tools/serve_pokedex.cjs
node tests/pallet-browser.cjs
```

构建会自动调用界面提取器。另一台机器需要相同的本地来源 ROM。源 ROM、解码 PNG、像素数据包、生成头文件及最终游戏 ROM 都留在忽略目录，不提交 Git。GBA 显示适配使用这些资源；共享 C 剧情、队伍、战斗规则与存档格式未改变。已有冒险可继续读取，不要求新建存档才能看到新界面。

## 验证

实际 mGBA 正常按键路线包含：图鉴启动、伙伴领取、背包三个口袋、战斗主指令、招式与返回、战斗背包投球、拒绝捕获训练师宝可梦、换人列表、开场任务、购物、保存／继续、旧存档迁移和坏槽回退。

`tests/test_game_ui.py` 检查图块排序／翻转、26 块来源数据哈希和全部输出像素包，并逐像素核对实际模拟器截图中无文字／角色遮挡的草地、室内与背包区域确实等于提取资源。测试不会修改 ROM 内游戏进度；截图为实际输出。

浏览器另检查存档导入导出、音效开关、键盘／触屏入口及三种视口宽度。真机与全套战斗动画仍未验证。截图和对应 ROM 哈希位于本地 `build/pallet/`，不把旧截图当作新构建结果。
