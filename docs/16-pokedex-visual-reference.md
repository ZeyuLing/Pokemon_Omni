# 游戏内图鉴外观重做

2026-09-20。以用户提供的西班牙火箭队内置修改器版 ROM 为实际视觉参考，重做 GBA 图鉴显示层。原版界面是在本地 mGBA 中运行后查看，不是根据网页图或印象推测。

## 参考与实现

原版列表页具有绿色横向条纹、左侧收集统计、中间精灵预览、右侧黄色编号列表和滚动条；详情页具有顶部按钮、浅灰信息框及下方说明区。本次沿用这些视觉结构，并为 Omni 的更多资料页面调整布局。

- 列表：收集统计、精灵预览、六行编号列表、选择高亮、滚动条、选中条目的完整名称栏。
- 形态名称：列表使用 `Mega`、`极巨`、`超巨` 的短标签；过长条目标记省略，完整名称仍在名称栏和身份页可读。基础种与各特殊形态仍独立登记。
- 基础页：顶部资料／招式／培养／更多指示、精灵预览、属性、编号／形态以及六项种族值条。其他详情页以统一的窗口和页码承载 15 页资料；左右翻页与 SELECT 目录不变。
- 字体：图鉴使用原生 12px 中文位图字体，世界、对话框等既有 16px 字体保持原接口。组合音标名称先进行 NFC 归一化，字形覆盖不足会阻止构建。
- 图片：主预览先去掉源图透明留白，再将可见内容以最近邻适配至最多 56×56 的范围，居中放入 64×64 画布。异色／背面图像页保留既有变体像素。这里是运行时素材适配，没有生成替代精灵画稿。
- 性能：大面积矩形使用同步 DMA3 填充，小字形和精灵像素使用 CPU 绘制，避免重画期间错过短按键。
- 入口：默认启动直接显示游戏内图鉴，保留调试需求。

这是根据参考重做的 Omni 界面，未声称逐像素复制火箭队的全部动画、叫声或页面功能。

## 验收

- 游戏 ROM 24 MiB，独立图鉴 ROM 23 MiB，均在标准 32 MiB 预算内；发行全内容的容量可行性仍须另行评估。
- 图片负载共 7,808 个唯一图像，包括新增主预览版本；图集 15,914,568 字节。`tests/gba-assets.py` 独立逐像素核验全部负载与固定来源的转换结果。
- `tests/gba-font-pixels.py` 直接从固定 BDF 读取字形，对比实际 ARM ROM 截图中的中文，不依赖生成字形索引。
- `tests/pallet-smoke.cjs`：新存档直接打开图鉴、15 页导航相关流程、短按输入、领取与登记、保存／继续、损坏槽回退通过。
- `tests/gba-smoke.cjs`：独立图鉴启动、页面、登记与存档恢复通过。
- `tests/pallet-browser.cjs`：浏览器实际 ROM、导入导出、输入与 320／390／820 宽度通过。
- 人工查看实际 ROM 的列表、基础资料、进化说明、异色图片画面；本次没有进行物理 GBA 设备验收。
