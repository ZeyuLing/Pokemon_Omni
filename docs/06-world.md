# 全地区、剧情改编与成长曲线

最终目标包含九个主地区与重要扩展地区，另设洗翠时代章节和新作预留。`content/regions/index.json` 当前为 14 条规划记录，不代表 14 张已制作地图。

共享世界以语义地点、人物和章节定义，GBA 的 2D 降维是一个平台呈现方案。未来 3D 地形/导航/场景可重新构建，仍引用相同地点 ID 与共享任务图；不从 GBA 地图脚本反推剧情逻辑。

## 剧情整合原则

2026-09-20 方向更新：采用熟悉角色参与的独立改编世界线，优先以小智等角色为主角，允许重写人物经历与立场。组织、政治与跨地区利益成为主线，道馆挑战占其中一部分。具体提案见 [剧情方向](19-narrative-direction.md)、[人物与真新镇开场](20-cast-and-opening.md)；研究事实与原创设计分开记录。

以下经典版本是素材与主题覆盖清单，不要求逐段照演全部原作事件。各地区由同一世界的因果与人物关系连接；原作中的冲突可重写、合并或成为有来源的历史档案。互斥版本和动画／游戏人物设定必须明确取舍，不能把每代完整主角经历无解释地全部安在同一个人身上。新剧情目前是设计稿，尚未进入 ROM。

## “全地图”的验收定义

建议保留城市、道路、洞窟、岛屿与关键室内空间的连通关系、探索内容和标志性建筑；把 3D/开放世界转成适合 GBA 的分区 2D 地图。不能用一张地区选择菜单代替地区，也不能声称逐像素复刻 Switch 世界。

每张地图至少验收：视觉风格、碰撞、入口出口、NPC、遇敌、隐藏物品、昼夜/天气条件、任务依赖、逃脱/飞行、复活点和剧情后状态。地图宏观拓扑与玩家可访问性分别验收。

不把神秘礼物、联机限定、版本限定变成永久不可得。通过本作公开任务/交换 NPC/对战奖励提供全图鉴获取路线；每只物种至少一条可达路径，追踪时期与难度限制。所有形态收藏目标另受存档预算约束。

## 跨地区等级曲线

持续提高等级无法支撑九个地区。建议保留玩家真实队伍与收藏进度，每地区提供本地成长章节、可选新队伍和阶段等级上限；正式训练师比赛在战斗副本中归一到所选格式规定的等级，结束不修改真实等级/成长记录。

新地区允许带老伙伴，不强制删队；新手章节的赛制可限制出场数、公开物种池或采用借用队，但限制必须敌我一致。探索体验通过新遇敌、移动能力、支线与可用战术工具推进，而非重复刷到 100 级。

用户确认的一周目道馆解锁等级上限规则继续保留，降低道馆剧情篇幅不会自动取消等级节点。跨地区归一赛制是另行设计的竞技格式，不能覆盖困难／疯子难度的剧情 NPC 等级政策；具体规则以 [对战政策](10-battle-policy-legality.md) 为准。

竞技难度与收集成本拆开：疯子难度提高对手策略并包含已公开的首领特权，不延长孵蛋/努力值重复劳动。提供可追踪的养成入口与合法配队教学。

## 世代机制保留方式

默认采用一套冻结的现代回合制基础规则；各历史章节若要复现旧世代机制，使用显式版本规则包，而不是到某地区就悄悄改变属性/招式。

地区体验保留其标志性玩法：丰缘的对战设施、阿罗拉试炼、伽勒尔赛事、朱紫多线探索。需要额外架构的三打、轮盘、群战、突袭、动作捕获等分别列为独立功能，不因功能表写有“全世代”就算自动拥有。

未来支持历史规则时必须包括该代招式数据、特性、伤害/行动顺序、合法性与联机版本，而不只是 `GEN_3` 等几个宏。一个 ROM 支持多套运行时规则的额外空间需重新评估。
