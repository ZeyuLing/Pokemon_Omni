# Omni 世界地理制作约定

2026-09-25，依据用户明确的制作标准：允许原创完整世界地图；新增地理不能与原作地区地图中已经确定的地理冲突。

本文件更新 docs/28 中过度严格的全球位置限制。没有官方世界坐标不再是制作阻碍。旧概念图仍不恢复，因为其地区内部海岸和地貌没有校准。

## 约束如何落地

| 原作已知内容 | 世界地图必须保留 | 可以继续创作 |
|---|---|---|
| 已显示的南部海域和海岸 | 该范围保持水域，原有海岸与水路不变 | 在已知海域之外新增岛屿或另一大陆；不能把海岸紧接成山地 |
| 陆地、山脉、河道延伸到图幅边缘 | 保留已显示地貌及其出口方向 | 在未展示区域延伸、转折或自然结束，需说明衔接 |
| 地区间已有陆路与相对方位 | 连通性、连接地点和方向 | 路线以外的新腹地，不能横插海峡切断原路 |
| 图片裁切、装饰云层、没有地形信息的留白 | 标为未知，不当作海洋或陆地证据 | 结合相邻资料设计，记录设计选择 |
| 同一地区不同时代 | 使用同一地点身份，记录年代差异 | 新旧设施、道路与政治边界可随剧情改变 |

“南方有海”约束的是原作实际展示的水域，并不意味着整个星球的南半部都必须是海。约束按海岸段、出口和已知区域记录，不能把一个地区的整条矩形边缘粗暴标为同一种地形。

## 世界底图制作顺序

1. 固定来源版本，标出已知地形范围、海岸段、陆路出口和不确定边界。宣传插画、城镇地图和可玩场景数据分别使用；格位留白不等于水域。
2. 在统一画布上安排地区位置。全球方位、距离、外部陆块和海域是 Omni 设计，不要求找到不存在的官方坐标证明。已有地区间关系仍是硬约束。
3. 在保留地区内部方向和拓扑的前提下统一制图比例，不镜像或旋转地区去迎合现实国家形状。不同来源比例差异需做地标对齐，不能任意拉伸地区内部路线。
4. 补画未知区域，检查接缝处海陆、山脉、河流及交通是否合理；远洋另一岸可以是山地，但不能覆盖原作已知海面。
5. 叠加城市、港口、航线和历史边界。宏观布局、已核对的地形、美术完成度、游戏可玩状态分别记录。

## 布局登记与审查

地区 `global_coordinates` 可以登记二维制图坐标；它是设计坐标而非经纬度。非空时，需要 `placement_review`：

```json
{
  "status": "reviewed",
  "basis": "omni_authored",
  "document": "research/geography/某次布局审查.md"
}
```

审查文档应记录所用世界坐标系、来源版本、涉及的边界段、保留的既有连接、原创接缝与发现的冲突。`reviewed` 表示作者完成并记录了相容性审查，不额外要求用户逐次批准，不代表官方设定或可玩地图验收。

程序只检查坐标格式和审查文档存在；当前没有地形掩码，不能自动证明海陆不相交。不得把通过数据检查写成“所有地理冲突已自动排除”。

当前 atlas.json 仍是参考图册，全球位置尚未落位。下一份统一地图应以本约定制作，而不是继续以“没有官方全球图”为由停留在分幅阶段。
