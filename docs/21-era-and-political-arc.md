2026-09-21 前史更新：用户已指定 1942 年坂木、大木、虹色之羽与希尔弗资助火箭队的起源，文学稿见 [《虹羽之约》](25-rainbow-covenant-prologue.md)。这一最新方向优先于本文未定的前史提案。以下政府／联盟分工仍可作为后世演变方案，不能无说明套用为 1942 年既定制度；小智出发的绝对年份与人物出生年尚未锁定。

## 1. 世界处于什么时代

2026-09-22：人物年龄与前史的工作年份已整理到 [主时间线](26-master-timeline.md)。它为下文第 0 年提供暂定的公元映射（1967），并区分官方信息与本作取值；本页跨年成长阶段仍为篇章提案。

2026-09-23：新增 [关都联盟的清洗／红莲事件](27-kanto-purge-outline.md)，拟排在 1943 年。用户的前史使用兼有政府职能的联盟；其内阁、冠军、四天王关系与下文后世制度提案分开，不能将所有时期的权力结构混用。

推荐的历史参照是幕末到明治初期：旧地方势力参与建立新秩序，随后却要面对交出原有权力的要求；改革者需要新的财政和武装基础，企业与地方人物因而获得议价能力。历史参考仅用于理解制度重组，不将现实人物、国家、民族或价值判断一一替换成宝可梦角色。

《大明王朝1566》继续提供场景写法：人物在会议上争执的事项，背后是升迁、责任、财政与派系关系。上级一句模糊指示可以让下级承担严重后果；某个当下合理的妥协，也可能成为几年后的罪证。

本作仍有现代宝可梦中心、图鉴、交通、通信和精灵球技术。时代变化发生在这些条件下：技术与强大训练师的力量改变了地方自治、政府治理和跨地区安全的关系。**不把古代服饰、武士身份或真实 19 世纪日历强行覆盖现有地区。**

### 原创的时代前史草案

| 时段 | 发生什么 | 对主线留下什么 |
|---|---|---|
| 小智出生前一代 | 部分地区经历过武装冲突，随后达成有限的地区间安排 | 老人、军人和地方家族对安全与秩序有不同记忆；具体参战方未定 |
| 小智童年 | 联盟、地方道馆与企业帮助恢复稳定，也保留各自网络 | 一些公众尊敬的人同时握有私人筹码 |
| 少年关都篇 | 火箭队事件暴露旧安排中的漏洞，政府与联盟开始争取改革权 | 经典胜利成为重新任命干部与调整权限的政治机会 |
| 后续周目 | 地方反抗、组织重组、技术危机交错 | 原本合作的改革者开始决裂；旧敌可能成为有限盟友 |
| 青年后期 | 是否继续集中权力、由谁监督与承担责任，成为公开冲突 | 结局由多年形成的人物关系与实际行动决定 |

马志士在游戏台词中提及战争，只能支持“有战争经历的角色”这一事实。它不能证明上述战争的名称、参战地区、年代或结果。那些内容必须按 Omni 原创历史建立，不能借一句原作台词宣布“官方暗示了关都世界大战”。

## 2. 政府真正掌握什么

不用“联盟”同时代称所有公共机构。先在关都建立一套清晰的小规模制度，再按各地区历史调整，避免全世界复制一张官职表。

| 机构／力量（工作名称） | 正常权限 | 受谁制约 | 可产生的政治冲突 |
|---|---|---|---|
| 关都地区政府与行政负责人 | 公共预算、行政任命、警务协调、依法启动紧急状态 | 地区议事机构、法院、地方执行部门与现实支持基础 | 安全部门扩大权限；改革派与地方派争夺关键任命 |
| 地方政府与警察 | 地方治安、执行调查和救援；君莎是角色／警务人员，不是一个万能机构 | 地区法律、法院与上级命令 | 拒绝违法命令、被撤职、案件被移交、执法失去资源 |
| 法院与检察／调查机构 | 审查拘押、调查犯罪、裁判与追责 | 程序、证据、任命与现实政治压力 | 证据封存、法官被更换、调查权限争夺；有敢追查的成员 |
| 关都联盟 | 训练师认证、比赛与道馆资格；受政府授权的危机行动 | 与政府的授权协议、内部规则、训练师与公众信任 | 联盟想保住自己人；政府借丑闻整顿联盟；四天王并非一派 |
| 道馆与馆主 | 竞技认证、训练及有限地方防卫职责 | 联盟资格审查、地方任命／认可与政府法律 | 资格合格却涉嫌犯罪；地方名望抵抗撤换；继任者获得旧网络 |
| 公共武装／应急训练师队伍 | 经合法指挥保卫设施、应对武装威胁与大型危机 | 政府指挥链与明确的地区授权 | 指挥权易手、部队拒令、以危机为由介入地方政治 |
| 企业、研究机构与地方家族 | 私有资源、研究、雇佣与社会关系 | 法律、许可、市场、竞争者与地方依赖 | 政商交易、隐瞒研究责任、出资支持某派或抽走支持 |

道馆任免采用双重门槛草案：联盟评估竞技资格，地方／地区机构审查公共任职资格；涉及犯罪时由法定机构处理。它解释了为什么“打败馆主”与“撤掉馆主”是两件事。坂木受到保护的具体链条要靠剧情证明，不能仅以双重身份推断全部机构共谋。

冠军不会自动成为最高行政长官。他可以具备极高声望、强大战斗能力和支持者，从而让政府无法忽略；这种实际影响力与法律职权的落差，正是冲突来源之一。多个地区仍有各自政府，跨地区组织不能默认在任何地方随意逮捕人。

### 如何把残酷政治写成玩家能参与的事件

| 争夺 | 剧情可以付出的真实代价 | 可玩行动与结果 |
|---|---|---|
| 抢夺接管火箭队资产的权力 | 证人失踪，调查人员被撤换，某个干部被当作替罪者 | 保护证人、追查委托、选择向谁提供证据；不能打赢就自动结案 |
| 借技术危机扩大紧急权 | 地方被封锁，伙伴被征用，一位反对者遭拘押 | 阻止征用行动、护送受影响者、争取撤销命令或保护反对者 |
| 联盟与政府高层争夺继任位置 | 暗杀、栽赃、政治清洗或迫使昔日盟友背叛 | 可阻止一项具体伤害，也可能让另一派坐大；不写成全员皆可无损救回 |
| 旧盟友分裂 | 青年小智的同伴被要求站队，公众评价变化 | 谈判、对战、证据公开与私下交换产生不同长期后果 |

这些是冲突类型，不是要求每一章都安排暗杀或死亡。暴力有下令者、执行者、受害者和受益者；受益不自动证明主谋。对明确发生的恶行保持责任判断，允许个人动机复杂。政治阴谋不能永远停留在一份意义不明的文件上。

## 3. 多年、年龄与周目

周目是玩家对后续大篇章的称呼。设计上用同一存档的世界年份与故事阶段表示；实际名称可采用“关都篇”“城都篇”等。不会重置全部事件来假装时间前进。

| 暂拟阶段 | 世界相对年份／小智年龄 | 主要篇章建议 | 人物与政治视角 |
|---|---|---|---|
| 少年第一次旅行 | 第 0–2 年／约 10–12 岁 | 关都、七之岛及必要后日谈 | 认识伙伴与道馆，亲历火箭队事件；看到政治伤害，尚不掌握全貌 |
| 少年后期 | 第 3–5 年／约 13–15 岁 | 城都与关都回访 | 旧干部与新馆主出现；被歌颂的胜利产生了不同后果 |
| 青年过渡 | 第 6–8 年／约 16–18 岁 | 丰缘、神奥 | 声望与经历让他成为各方争取的人；开始参与有条件的组织行动 |
| 青年卷入核心冲突 | 第 9–11 年／约 19–21 岁 | 合众、卡洛斯及跨地区回访 | 选择理念、联盟与责任；长期盟友的决裂形成主线高潮 |
| 青年后期 | 第 12–14 年／约 22–24 岁 | 阿罗拉、伽勒尔、帕底亚与终局回访 | 决定如何面对集权、地方利益和旧承诺，保留多种政治结局空间 |

这是一套一致的工作日历，**不是官方时间线，也不是已经锁定的五次通关安排**。具体年龄可调整，但不能在某个地区突然恢复成十岁。同伴按各自出生年份同步成长，年长角色有不同的职业与生活阶段。

时间可以通过明确的“翌年”“三年后”等章节过渡前进，中间用少量可玩回家、训练、探访或新角色事件维持连续感。一个联盟赛季结束适合作为跳跃节点，但不是每次通关都必须立即跳三年。重大关系转折应发生在可玩剧情中，不能全部放进跳时字幕。

### 跨年时玩家资产与任务如何处理

- 所有伙伴、收藏、已完成任务与个人选择保留；不通过删除队伍解释年龄变化。
- 世界时间不随挂机、读档次数、刷路人或查看图鉴前进。路人仍按已确定政策更新进度与等级。
- 跨年入口先列出会变化的任务、角色位置和地区状态，自动保留阶段存档；玩家选择继续当前时代或进入下一阶段。
- 重要故事任务应完成或获得明确的替代后续再跨年。可错过的支线提前说明，收藏类内容提供当前年代的等价获取途径。
- 旧时代可用回忆或挑战回放访问，但回放不能重复产出稀有奖励或改写已经确定的当代事实。
- 玩家见过而小智尚未知晓的过场信息单独记录；不能用观众视角材料直接解锁角色证据选项。
- 高等级旧队伍与后续地区难度是另一个设计问题。保留现有等级上限和 NPC 政策；不偷偷降级或强制丢队，也不宣称年龄系统已解决全地区成长曲线。

## 4. 关都：经典事件必须留下来

来源类别：动画 EP001–002 提供出发和初遇关系；火红／叶绿等关都游戏提供地图与关键组织事件；本作新增的是背景、政治过程和持续后果。表中“政治扩展”全部为 Omni 原创。

| 锚点 | 保留的经典体验 | 政治扩展 | 不能随意推翻的内容 |
|---|---|---|---|
| 真新镇出发 | 花子、大木、小茂、领取伙伴与旅行愿望；采用皮卡丘开场 | 新闻或长辈的一句背景话，后续才有意义 | 不替换成执行调查任务；不让少年先当政治办事员 |
| 一号道路与常青市 | 和伙伴建立信任、小霞的相遇、中心与三人组初次冲突 | 事件后的警务关系与常青道馆反差 | 三人组初期盗取宝可梦的行为仍需负责 |
| 月见山 | 洞窟、化石与火箭队活动 | 开采、研究利益与地方许可存在不同参与者 | 游戏中关于出售化石的目的不被伪装成纯公益行动 |
| 道馆之旅 | 小刚、小霞、马志士等强敌与训练师成长 | 地方职责、退役者经历、任命与资源关系 | 道馆不是全都腐败；真实战斗胜利仍解锁规定的成长节点 |
| 玉虹赌场据点 | 潜入火箭队藏身处，得到推进紫苑塔的观察工具 | 谁允许产业与地下组织共存，干部间如何分配利益 | 原事件必须可玩，不能只剩一段“过去赌场出过事”的说明 |
| 紫苑镇宝可梦塔 | 卡拉卡拉、嘎啦嘎啦、富士老人，面对火箭队造成的伤害 | 案件如何被处理，谁试图淡化或追究责任 | 不把死亡改成误会，不让未来合作自动洗掉组织责任 |
| 希鲁夫公司 | 被占领的公司、营救、坂木与大师球技术争夺 | 政府和联盟争管辖，企业管理层也有自身议程 | 员工真实受到威胁；新增阴谋不能说此前全部救援都是演戏 |
| 红莲研究遗迹 | 探索与超梦有关的研究记录 | 项目资助、危险研究许可及各代负责人 | 游戏、电影的研究者和资助链先区分，再明确本作取舍 |
| 常青道馆 | 面对馆主坂木及其双重身份，获得旅行中的关键胜利 | 资格吊销、追捕／出逃、地方继任与旧网络接管 | 打赢不自动让主角成为馆主，也不等于所有地下网络消失 |
| 联盟赛与后日谈 | 与强敌对战，检验自己和伙伴的成长，回到家乡 | 谁利用表彰、谁拿到接管权限，为下一年代埋伏笔 | 不强制照搬动画固定淘汰或游戏必然冠军；胜负分支需尊重实际结果 |

后续地区按同样方法制作事件清单。全地区的大体方向保留；未完成逐场景核对的部分不得标成已确定剧本。

## 5. 一个跨年的政治故事示例：坂木败退之后

下面是原创因果提案，不是原作隐藏真相。

少年关都篇，小智阻止希鲁夫行动，又在常青道馆击败坂木。成年人中有人认真追查，也有人急于宣布局势已经恢复。支持小智的联盟人物协助调查，确实使受害者得到保护。

进入后续周目，地方换了馆主，部分火箭队干部被捕，部分以提供情报为条件获释。小智以为火箭队只是卷土重来，城都却让他看到：某些地方势力曾经依靠坂木维持平衡；新任接管者为了立功，继续使用原有的渠道与线人。一位几年前给过小智帮助的调查人员，因追查接管后的交易失去职位。

到青年阶段，当年的支持者主张把更大的行动权交给中央化机构。他的理由有真实基础，也得到受害者支持；他同时准备牺牲几名知情人来促成政治交易。坂木可能提出合作，提供只有旧组织掌握的材料，并要求恢复自己的某项利益。

小智可以阻止一次清洗、揭穿一项交易，或建立不依赖坂木的证据路径。每条路线改变下一轮力量分布。经典打败坂木的经历保留了价值；多年后的责任让那次胜利拥有更长的故事。

## 6. 多年成长对共享架构的要求

以下仅为设计契约，不是已实现接口：

| 数据 | 共享核心负责 | 表现层负责 |
|---|---|---|
| 世界年份与篇章 | 通过明确事件推进，校验前置与任务处理；一次提交全部状态 | 年代标题、回顾与转场 |
| 人物身份 | 固定人物 ID、出生年或稳定年龄段、当前职务、私下所属、已知事实 | 少年／青年／年长立绘、模型、动作与声音 |
| 地点变化 | 以地区阶段选择 NPC、通行和事件内容 | GBA 图块与未来 3D 场景各自呈现同一阶段 |
| 伙伴与历史 | 获得时间、参与事件、选择与奖励领取记录 | 回忆、图鉴或状态页中的共同经历 |
| 存档迁移 | 版本号、稳定事件 ID、跨年事务标记与恢复路径 | 保存槽 UI、明确告知当前年代 |

出生年份与岗位不可直接绑定同一字段；换制服不等于换身份，年龄变化不自动更换阵营。移除或替换的事件 ID 需有迁移记录。GBA 的空间成本要实测，不能把多年全地图每个瞬间完整复制进存档。

制作前验证：跨年前后保存与读取不丢伙伴；年龄计算一致；同一事件不可重领；旧任务能完成、转移或明确结束；所有难度共享剧情事实；GBA 与宿主使用同一 C 核心和事件数据得到相同后果。
