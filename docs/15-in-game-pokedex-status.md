# 游戏内图鉴验收状态

2026-09-20。当前优先级是把游戏内图鉴做好，暂停扩展地图与剧情。**图鉴已经嵌入真正的 GBA 游戏，但仍不能称为全部完成。** 本文取代文档 13 中关于图鉴页数、图片数量、容量及缺少道具说明的旧状态；文档 13 保留首轮实现和来源说明。

## 调试入口

默认构建启动即打开游戏内图鉴，游戏菜单也允许未领取伙伴时查看。图鉴列表按 B 返回标题。读取已有存档同样先打开图鉴，不会自动发放伙伴、推进剧情或登记捕获。`tools/build_pallet.ps1 -StoryStart` 可构建保留领取门槛的剧情启动版本；当前 `/play` 提供默认调试版。

## 已接入实际游戏的功能

`build/pallet/omni-pallet.gba` 为 20 MiB，独立联调图鉴 `build/gba/omni-dex.gba` 为 19 MiB。二者共用同一个图鉴适配器和便携 C 图鉴核心。无需浏览器也可在 mGBA 运行；尚未进行物理 GBA 测试。

目录保持 2,384 个物种／形态／战斗状态条目。参考信息可浏览，遇见、捕获、形态解锁仍由游戏事件独立登记；打开资料不会伪造捕获记录。23 条火箭队羁绊仍是研究只读条目。

详情现在有 15 页，可左右翻页，SELECT 打开目录直接选择：

| 页面 | 内容与边界 |
|---|---|
| 基础与种族值 | 中文名称、属性、特性、分类、图片、六项种族值 |
| 招式与学习来源 | 招式列表、属性／分类、威力／命中／PP；A 依次看参数、效果、学习来源、返回列表；来源代码译为世代和学习方式 |
| 推荐配装 | 道具、特性、性格、四招；上下更换方案 |
| 努力值与个体值 | 六项 EV／IV 与来源赛制 |
| 同物种形态 | 独立形态列表并切换到对应条目 |
| 名称与登记记录 | 完整名称、全国编号、当前记录状态 |
| 特性详细效果 | 普通／隐藏特性及固定参考库效果；长文本上下滚动 |
| 进化路线与条件 | 前置进化、后续进化与现有条件摘要；来源条件尚未全部接入游戏进化事件 |
| 形态变化与机制 | 来源转换说明、所需道具／招式、机制备注与待审定边界 |
| 携带道具说明 | 当前方案道具效果、经同套四招校验的替代道具；A 切换方案 |
| 配装思路与赛制 | 定位、完整道具／特性／四招名称、性格、等级、单打／双打、太晶属性、现有策略说明和来源；A 切换方案 |
| 本项目获取与登记 | 三只初始伙伴明确显示大木研究所三选一，其他条目标记未配置；不把原作地点当成本项目地点 |
| 资料详情与核验 | 完整中英文名、身高体重、已有物种参数、数值／招式／特性核对状态 |
| 图片与异色 | 上下切换正面、背面、异色和雌性变体，共八个槽；无来源的槽明确显示无图，不生成替代图 |
| 实际 HP 计算 | 等级、HP IV／EV、极巨等级；上下选字段，A 加、START 减；仅已有极巨化／超极巨化条目显示极巨 HP，不能用计算器证明某物种具有该机制资格 |

基本操作仍是 A 确认、B 返回，L/R 更换条目。长文本页上下滚动到底，不会仅显示前几行。列表筛选支持编号、分类、世代、属性、记录状态和研究条目；名称输入仍为英文键盘。

极巨化不改变基础种族值；实际最大 HP 调用共享 C 的计算函数，并保留脱壳忍者固定 1 HP 例外。本轮未修改物种的极巨化资格清单。

## 素材、说明与配装来源

- 全部现有图片变体共有 6,628 个输入引用，缩放到 64×64 后去重为 6,279 个 RGB555 图像；本机下载缺失数为零。图片仍是来源参考图适配，不代表全部已制作成发行美术。
- 每幅图独立采用 RGB555 游程压缩或原始存储回退，保留缩放后像素精度。图集共 11,793,750 字节。绘制直接解码到显存，不增加整幅图片的常驻解压缓存。
- 源 URL 与 SHA-256 在 `assets/source/gba-reference-images.json`；图片、ROM、字库、工具链与最终 ROM 不提交 Git。
- 招式／特性说明由 `tools/legality-reference/dex-descriptions.cjs` 从锁定的 `pokemon-showdown@0.11.11` 读取。说明目前是第九世代默认参考库的**英文原文**，不能假定适用于所有历史赛制，也不等于 Omni 已实施该效果。没有说明的条目明确标为待核实。
- 配装仍为 987 套、覆盖 324 个精确形态；来源赛制的单只完整组合通过固定 TeamValidator。没有为缺失形态编造方案，也没有宣称这些是本项目最优解。

## 实际验收

构建：`tools/build_pallet.ps1` 与 `tools/build_gba.ps1`。验证：

- `tests/gba-assets.py` 独立解码全部 6,279 个图像负载，与固定源图经相同缩放、透明阈值和 RGB555 转换的结果逐像素比对。
- `tests/pallet-smoke.cjs` 通过正常游戏流程获得图鉴；`tests/gba-dex-pages.cjs` 在实际 ARM ROM 内操作目录、进化、特性、招式效果／来源、道具、策略、获取／核验、图片和 HP 页面，并把长文本滚动到底。正面／背面／异色显示逐像素比对。
- 同一次实际游戏测试验证领取、记录、保存／继续和最新存档槽损坏回退。探针只用于读取界面状态，没有注入或修改游戏状态。
- `tests/gba-smoke.cjs` 验证独立图鉴 ROM 的导航、字体像素、登记与双槽恢复。
- `tests/gba-host-wasm.cjs` 运行同一份 C 宿主接口测试。Windows 应用控制此前阻止新生成的原生测试 EXE，因此改为 Wasm 执行，没有关闭系统策略。
- `tests/pallet-browser.cjs` 验证实际 ROM 播放器、存档导入／导出保护、独立图鉴隔离、音效控制及 320／390／820 宽度布局。

构建哈希与验收结果在 `research/in-game-dex-validation.json`。最终 ROM 校验会拒绝过时图片／字库嵌入，并检查 32 MiB 容量与 GBA 文件头。

## 尚未完成，不能计为已交付

1. 全部招式、特性和条件的中文说明与逐项审校；部分效果目前仍是英文，部分条件仍为来源文本。不同世代的效果差异尚未制作成可切换的说明库。
2. 全部形态的可靠培养方案；现有 324 个形态之外显示无已核验方案。
3. 23 条火箭队羁绊的完整触发／解除规则、专属招式合法性和本项目战斗审定。已有图像与种族值的双 ROM 核对不能替代这些工作。
4. 全世界获取地点、捕捉剧情门槛及实际进化事件接线；目前只有初始伙伴获取信息与游戏事件一致。
5. GBA 中文／拼音输入、收藏和多条目对比等便利功能尚未实现，网站具备的功能不能算作游戏内已经具备。
6. 发行美术、真机兼容性／性能／掉电存档验证，以及与完整战斗系统的集成验收。

只有上述所需内容明确完成或经用户调整范围后，才能把“游戏内图鉴完整做好”标为完成。目录条数、图片覆盖和页面可打开都不单独构成整体完成证明。
