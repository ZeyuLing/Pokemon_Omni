## 开场《未竟的和平》

时间只写“第一次宝可梦世界大战末期”。以下是对已经采用的背景做蒙太奇呈现，不给红莲事件后的未写历史、世界赛举办日期或条约签署补时间。

| 镜头 | 玩家看到的内容 | 隐藏信息边界 |
|---|---|---|
| 战争末期 | 疲惫的城镇；胜负未分，生活已经难以为继 | 不虚构新战役、受害者或死亡 |
| 宝可梦中心 | 宝可梦仍被送回战场，人们等待不必再战的一天 | 没有新增医疗故障开局，仍回到经典真新镇起点 |
| 世界赛提案 | 每四年以比赛代替战争，胜者执掌拟议中的世界联盟，前四名议政 | 这是提案，不擅自变成已经签署生效的联邦条约；完整资格和两院制度沿用文档 32 |
| 渡 | 统一各地区的目标与新的赛场 | 不补新部下、师徒关系或具体暴行 |
| 希尔弗 | 商店、医疗与货物流通，更大市场的诱惑 | 不使用 1942 年老总充当未知的当代家主，不新增具名发言人 |
| 坂木 | 有冠军履历却无法报名，仍追寻神兽力量 | 没有替他恢复身份或宣布成功捕获神兽 |
| 下一代 | 强者培养接棒人，年轻人也有自己的道路 | 小茂立绘不等于确认其政治服从；新候选的阵营与相遇尚未写定 |
| 大木研究所 | 深夜未熄的灯、反复推演的对战；“知道怎样赢，还不够。”“还要知道，为什么而战。” | 可先理解为训练与研究，后期可重新解读；不出现 AI、VLM、PROMPT、人工身体、赤红／小智研发标签或培养舱 |

运行文本只从 `content/opening/prologue.json` 编译，不从包含小智秘密的编剧人物档案直接导出。源地图裁切为舞台画面；不把地图室内布置当成新地理或实际势力总部。动画的第一版为地图、立绘、字幕、淡入淡出与 PSG 配乐，尚不是完整角色走位电影。

新冒险先播放开场，播放完成或确认跳过后才初始化新存档。已有存档仍先要求确认替换。标题按 **L** 可回放；回放和画册不写存档。序章 **A** 翻至下一幕，**START** 打开跳过确认，**A** 跳过、**B** 继续。

## 人物形象与档案

目前编入 **22 张 80×80 立绘**：上一轮讨论的 18 位劲敌／关联人物，以及小智、渡、坂木、大木。标题按 **R** 打开开发画册，左右翻页、B 返回。小智立绘也用于训练家卡。

小智、小茂、阿弘、优藤圣代、小明、真司与小银、阿杏、碧蓝、叶子、艾岚、彼特来自两组 imagegen 初版图集。它们经过裁切、缩采样和 RGB555 编译，属于游戏立绘草案，不能声称是官方像素素材、服饰逐帧核对成果或完整动画。提示词及输出保存在 `assets/characters/`。生成图实际带有透明通道；编译时将 alpha 转为 GBA 的透明标记。它们尚未作为完整战斗动画套件使用。

小进、步美、小驱、青绿、阿桔、小椿、赤红、大木、渡、坂木使用 [Showdown 训练家素材档案](https://play.pokemonshowdown.com/sprites/trainers/) 中的现成像素立绘。小进素材署名 **kyledove**，步美、小驱署名 **Brumirage**；其余所选游戏像素列明 Game Freak／Nintendo／Creatures 来源。遵守来源的作者署名与未经许可不编辑要求：不重新绘制、不缩放，保留原像素，只作透明填边及 GBA RGB555 编码。第三方源图在忽略目录，URL、哈希、署名与处理方式纳入 Git。

新图集与小智行走图集的另外两次生成遭服务拒绝，记录请求 ID；没有转用收费 API。**小智地图小人仍是明确标注的赤红占位，完整四向行走、投球、战斗背面、青年中年与 3D 模型尚未完成。** 立绘可用不等于这些套件完成。

所有地图 NPC 实例继续关联人物档案；新增非剧内“序章旁白”记录，并为序章每位演员登记场景绑定。人物档案提供全部已写生平、来源版本、原作关系与创作留白；未知童年、未写几十年经历、未来与结局保持 `null`，不为了“完整”臆造故事。生成素材不能倒过来充当动画设定的考据证据。

## 音乐与倍速

ROM 增加三首短循环的原创 PSG 双声部草稿：序章、探索、对战。音效保留独立声道。背景音乐由 Timer 2／3 的 **64 Hz 硬件时钟与中断**驱动，每 20 个时钟推进一个八分音符，即 96 BPM；绘图和探索模拟不负责推进节拍。界面绘制期间也持续排音。公共计时与节奏状态机在 portable C，GBA 寄存器只在适配器。

探索中按 **SELECT** 循环切换 **1／2／4 倍行走模拟速度**，背景音乐、字幕阅读与菜单保持正常节奏；战斗当前没有可加速的完整动画系统，不把它宣传成全流程倍速。网页运行器仍以 GBA 原本的硬件帧率运行，使用 ROM 自带的加速。

**任意第三方模拟器自己的外部倍速不在这项保证内。** GBA 的声音与定时器本来就受 emulated CPU 时钟驱动，ROM 没有通用的宿主墙钟或统一快进通知协议。要在外部模拟器快进时保持音乐原速，需对应模拟器提供独立音乐时钟／音频协作，或专门的宿主音乐后端；本次没有伪称完成通用补丁。[GBA Direct Sound 硬件说明](https://gbadev.net/gbadoc/audio/directsound.html)、[mGBA 音频与快进设置实现](https://github.com/mgba-emu/mgba/blob/master/src/platform/qt/SettingsView.cpp)

## 构建与验证入口

```powershell
./tools/build_pallet.ps1
node tests/presentation-rom.cjs
node tests/pallet-smoke.cjs
python tools/build_story_bible.py
python tools/build_story_bible.py --check
python tests/story_bible.py
```

默认仍为直接进图鉴的调试 ROM；`-StoryStart` 构建标题开场入口版本。`-ReuseAssets` 仅供没有修改资源、脚本或字体的 C 代码迭代，正式验证使用完整资源构建。

ROM 自动检查序章手动／自动推进、跳过／取消、回放与画册不改存档、新冒险初始化时机、22 张不同画面及各速度下实际音频输出和硬件节拍。验证结果生成在 `build/pallet/presentation-test.json`，不以仅编译成功代替可运行验证。
