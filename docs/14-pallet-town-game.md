# 真新镇游戏基础版

当前调试构建启动直接打开图鉴，列表按 B 返回标题。未领取伙伴也可从游戏菜单查看图鉴。需要剧情启动方式时使用 `tools/build_pallet.ps1 -StoryStart`。

2026-09-20：将图鉴嵌入一个真正可操作的 GBA 游戏开场。当前 ROM 是 **Pokémon Omni · 真新镇**，20 MiB；从标题画面开始，进入房间、街道和研究所，完成伙伴领取与基础练习战，再保存并继续。此前独立图鉴 ROM 仍保留作模块联调工具，游戏入口改为 `/play`。

## 当前可玩流程

1. 标题选择新的冒险，出生在玩家房间。右上楼梯下楼，可以和妈妈交谈；电脑中有一次性的伤药。
2. 从一楼下方门口走到真新镇。镇内有玩家家、小茂家、大木研究所、路人和告示牌；房间、树木、家具、人物和水面具有碰撞限制。
3. 前往东南方研究所，与大木博士交谈。在桌上选择妙蛙种子、小火龙或杰尼龟；确认后得到一只 Lv.5 伙伴、图鉴和三瓶伤药。
4. START 打开图鉴、宝可梦、背包、训练家卡片或保存。伙伴自动加入队伍，物种自动登记捕获；练习战对手自动登记见过。没有向玩家开放“模拟捕获”的调试菜单。
5. 和小茂交谈并确认练习战。小茂选择属性克制玩家初始伙伴的另一只 Lv.5 宝可梦。战斗结束后恢复双方 HP/PP，首次完成获得 100 元，之后可由玩家主动确认重赛，不重复发放首次奖励。
6. 返回家中可恢复伙伴，在菜单保存后重启并选择继续冒险。领取伙伴、电脑取物、妈妈恢复及完成练习战也会提交保存。

操作：方向键行走，B+方向键跑步，面对人物／物品按 A，START 菜单，B 返回。图鉴中左右翻页，L/R 更换条目；列表 SELECT 筛选，详情 SELECT 打开页面目录。图鉴最新验收与剩余工作见 [游戏内图鉴状态](15-in-game-pokedex-status.md)。浏览器键盘映射为方向键、Z=A、X=B、Enter=START、A/S=L/R、Shift=SELECT；页面亦提供按键和可选确认音效。

## 代码与数据边界

| 所有者 | 内容 |
|---|---|
| `core/include/omni/adventure.h`、`core/src/adventure.c` | 稳定地点／人物身份、开场状态、交谈资格、一次性伙伴／物品奖励、队伍与恢复、练习战结算、逻辑存档 |
| 既有 `core/src/pokedex.c` | 查询、独立形态记录与 ODEX 保存；同一份源码用于游戏和网站 |
| `content/pallet-town/scene.json` | 地点符号 ID、GBA 人物摆放、对象与告示牌绑定、原创中文告示文本 |
| `adapters/gba/pallet_game.c` | 游戏主循环、2D 碰撞与移动、摄像机、层遮挡、行走帧、门／楼梯、菜单、战斗展示、提示音和 SRAM 事务 |
| `adapters/gba/pokedex_game.c` | 嵌入式图鉴界面；本游戏未定义 `OMNI_GBA_STANDALONE`，因此事件联调菜单关闭 |
| `tools/build_pallet_assets.py` | 固定来源验证、图块／调色板／碰撞与角色编译；不执行上游剧情脚本 |

共享 C 逻辑不读取 VRAM、GBA 寄存器、键盘、地图格子或浏览器存储。3D 适配可以通过地点切换、人物交互、选择伙伴、战斗动作等同一接口继续使用这些剧情和状态。当前是一个明确的开场状态机，不是已完成的通用任务编辑器、完整世界引擎或全部宝可梦规则运行时。

此切片使用自己的轻量 GBA 显示适配，未编译或接入完整 FireRed／pokeemerald-expansion 引擎。现有 RHH 候选与未来完整战斗迁移仍保留为后续工程事项，不能把借用地图资源当作已经接入上游全部游戏功能。

## 地图与素材来源

五个场景：真新镇（24×20 格）、玩家家一楼（13×10）、玩家房间（12×9）、小茂家（13×10）、大木研究所（13×14）。地图、图块、调色板和人物／初始伙伴精灵图取自 [pret/pokefirered](https://github.com/pret/pokefirered/tree/c75f352304d529f6ba92d4f74b9cf8b5c3810788) 的固定提交 `c75f352304d529f6ba92d4f74b9cf8b5c3810788`。

`assets/source/pallet-town.json` 记录 82 个源文件的固定提交 URL、SHA-256 与大小；脚本优先读取已验证缓存，缺少时取固定 URL，任何已记录文件哈希变化都会失败。地图、9 组人物／物体以及三只伙伴的正背图编译为约 891 KiB 的 GBA 资源。资源来源说明不意味着其美术归项目原创；本轮只提交导入脚本、绑定和清单，下载素材及 ROM 均在忽略目录。中文对白为本项目开场改写，没有直接运行或复刻完整火红剧情脚本。

画面使用 GBA Mode 3，地图按行 DMA 复制，角色使用方向／行走帧，前景遮挡由源图块层属性生成。场景摆放属于 GBA 适配，不作为未来 3D 的坐标真源。使用当前完整图鉴和其字库，不会在 GBA 上解析展示 JSON。

## 练习战的准确范围

当前仅支持三只 Lv.5 初始伙伴，每方一只；基础参数为中性性格、31 IV、0 EV。实现撞击、抓、叫声、摇尾巴和 PP 耗尽后的挣扎，含行动顺序与同速随机、PP、基础伤害浮动、要害、攻击／防御等级、挣扎反伤、倒下与结果。此招式子集没有招式命中率变化，普通攻击均按基础 100% 命中处理。

小茂的基础策略只使用公开 HP／能力变化和自己的 PP；这里没有运行完整搜索型 AI，也不把它命名为困难或疯子难度。练习战禁止背包使用和逃跑，结束自动恢复；没有经验／升级、捕获、六人队伍轮换、双打、天气、完整特性效果、Mega、Z、极巨化、太晶化或羁绊。现有难度与公平对战政策规格不等于这些机制已经在本切片全部接线。不会用这个基础结算器接纳超出三只伙伴和五种招式的对战。

## 保存格式

本游戏与独立图鉴使用不同魔数、浏览器存储键与下载文件名：`omni-pallet.sav` / `omni-pallet-sram-v1`。仍为 32 KiB SRAM，两个 16 KiB 槽，先写非活动槽内容，再提交有效标记并读回验证。损坏时选择上一有效槽。

每个槽的 `OMG1` 头包含序号、长度、负载校验和头校验。负载 `OPAL v1` 将 GBA 位置与朝向、132 字节 `OADV v1` 逻辑状态、完整 ODEX 图鉴区块放在同一事务中。逻辑状态按字段显式小端编码，不保存 C 结构体内存或指针。载入先验证所有区块、位置和数值，再同时替换游戏与图鉴状态。

冒险存档与纯 ODEX／独立图鉴 SRAM 不兼容；浏览器在替换当前进度之前校验格式、校验和、位置、伙伴和图鉴结构。保存校验是损坏检测，不是防篡改签名。本版不支持战斗中途保存，浏览器关闭时保留最近的实际游戏保存点。

## 构建与验证

依赖沿用图鉴：Zig 0.13.0、Node.js、Python 3 + Pillow，以及固定 GNU Unifont、mGBA Wasm 缓存。全图鉴本地素材依赖说明见 [图鉴构建](13-gba-dex-training.md)。

```powershell
python tools/fetch_gba_dependencies.py
# 尚未生成目录时，先运行 ./tools/build_pokedex.ps1
./tools/build_pallet.ps1 -Python python
node tests/pallet-smoke.cjs
node tools/serve_pokedex.cjs
# 另一个终端，在预览服务启动后：
node tests/pallet-browser.cjs
```

打开 `http://127.0.0.1:4173/play`，或使用模拟器载入 `build/pallet/omni-pallet.gba`。

测试包括：

- 共享 C 开场／奖励／保存／战斗测试：三种伙伴、120 个种子组合、1,255 个确定性回合，对相同输入逐步比较状态和事件；损坏保存不修改状态，重复领取和重复结算不重复发奖。
- 实際 ARM ROM 的按键流程：五张地图与往返门／楼梯、NPC 对话、电脑一次性物品、领取伙伴、图鉴解锁与嵌入、队伍、练习战、保存／继续、最新槽损坏回退。被动状态探针仅供模拟器读取，不提供注入、传送或修改状态入口。
- 浏览器：实际 ROM 启动、菜单与存档导入／导出、存档类型隔离、损坏导入保留当前进度、音效开关、键盘／屏幕按钮、820／390／320 像素布局及脚本错误检查。
- 既有网站配装、收藏、对比和独立图鉴运行器回归通过。

本机早期原生 C 测试通过；后续 Windows 应用控制阻止重新生成的测试 EXE，因此默认构建改为把**同一份 C 测试**编译成 Wasm 在 Node 运行，再执行真实 ARM ROM 的 mGBA 回归，没有修改系统安全策略。未进行 GBA 真机性能、烧录卡兼容或真实断电实验。

仍未完成：其他地区、野外遭遇与捕获、完整战斗规则和三档 AI、羁绊机制、完整成长与 PC 盒子、命名／角色选择、BGM 与完整演出、正式发布美术和真机验证。本轮目标是可以继续扩建的真新镇游戏基础版，不把以上功能标为已交付。
