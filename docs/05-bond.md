# 羁绊进化：采用火箭队名单，效果单独完善

按用户确认，首批名单以 Dragonsden 西班牙火箭队 2.1 为目标，不扩展到所有物种。重要 NPC 与部分普通 NPC 可有羁绊伙伴，队伍不要求六只。

名单研究见 `content/bond/rocket-2.1-roster.json`：作者公开帖的形态美术署名核对到 15 个名称；独立粉丝站另列 8 个候选。作者署名不等于完整 2.1 名单，粉丝站也非作者官网。23 条是待核实研究清单，未导入不明数值/素材为正式内容。需继续按作者附带版本文档确认完整名单、名称、属性与获得条件。

此前“三物种试点、占道具、三回合、和其他机制共享一次”的方案撤回，不作为既定规则。特殊机制独立额度；羁绊一次是建议默认，持续时间、道具要求、换下回退和激活条件尚待设计。永久 Mega NPC 禁用羁绊和其他机制。

进一步设计应围绕共同剧情经历与伙伴任务解锁、明确战术角色、公开反制与有限数值增长。羁绊不能仅靠重复刷弱怪无限增长。每个形态需给出完整招式/特性/形态交互表，并覆盖变身、接棒、抑制特性、换人、濒死、战斗结束与读档。不得复用已有 Battle Bond 特性 ID 来代表所有原创形态。

官方赛制仍不接受自创形态。完整政策见 [对战与合法性](10-battle-policy-legality.md)。
