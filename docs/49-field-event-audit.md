# 地图事件、对白等待与行进路线审计

2026-10-26。用户指出固定路线跑通不能证明碰撞和剧情不可绕过，并明确老人事件在交还博士包裹之后且不可跳过。

## 发现与纠正

旧开场有地块碰撞与研究所出发条件；没有覆盖所有触发路线。老人只靠 A 交谈且缺少包裹前置，可以直接不理老人。NPC 路线采样只查地块，没统一处理玩家和其他演员占位。普通场地对话一次呈现整页。旧录像把老人放在包裹前面，已撤回并重录。

核心现在先判持久剧情条件，再由场景适配器取得控制权。研究所赠礼未完成小茂战会恢复该场景；交还包裹后，常青市北行 y≤10 的整幅地图区域触发老人。老人先绕过当前玩家与家具走到相邻安全格，再提供教学／挑战；无需对准固定人物主动按 A。事件在完成脚下移动后优先于随机遇敌，世界空闲帧也优先于移动和 START 菜单检查，因此换速度、换路线或读档不能越过已进入的触发区。尚未北行时仍可在南侧自由活动。

对战入口另外检查已交还包裹，防止其他调用路径提前开始老人事件。完成标记和待领取礼物持久保存；战败可重试，旧存档的已完成记录继续保留。地图传送失败不会继续使用目标坐标。

NPC 路线使用共享 C 四邻格寻路，动态占位包含玩家、其他可见 NPC 与地块障碍。移动逐像素检查角色脚部碰撞，当前位置用于绘制、排序、交谈和阻挡。超出容量或不可达时返回失败，不输出半条路线、穿墙或瞬移。

场地消息采用逐字显示、当前页完成、等待确认、下一页／脚本恢复四个阶段。首次按 A/B 补全未显示完的页，下一次按键才继续；按键按按下边沿读取。全文显示后才画续页箭头。字形、框与箭头仍来自用户西班牙火箭队 ROM。

## 验证

- 共享核心遍历 2048 种标记组合与北行区域横向位置，检查包裹前置与完成后不再触发。
- 地图图搜索枚举当前南侧到北行区的全部可达入口；实际 ROM 用正常按键逐入口、逐 1/2/4 倍速度尝试绕过。测试会保存触发前进度、重启继续，再进入触发区。
- 演出期间按方向、START 和 R，不得移动玩家或抢占脚本；人物逐帧脚部不能进入家具、玩家或其他可见演员。
