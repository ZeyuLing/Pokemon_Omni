# 图鉴范围第一稿

更新：2026-09-18。全世代完整收录沿用用户目标。用户已同意单存档全物种可获得、幻之宝可梦专属支线及无需联网/现实限时活动，并进一步要求特殊形态正式进入图鉴。

## 修订：全图鉴以独立条目为单位

全国物种编号和图鉴条目 ID 分开。Mega、超极巨化、羁绊等特殊形态拥有独立可检索条目，在默认全图鉴列表中可见（随剧情显示未发现状态或剪影）；不是仅放在基础物种介绍中的附注。按物种聚合是可选浏览方式，不减少正式形态条目。

完整条目应提供名称、形态图、属性、种族值、特性、招式差异、触发/解除条件、获得资格和登记状态。临时形态通过实际目击/使用等规则登记，不要求非法捕捉永久形态；首领专用形态按剧情观察或击败登记。具体剧透隐藏策略待 UI 实现。

普通极巨化也可浏览对应状态条目；底层引用基础形态并应用机制修正，不复制数值表。普通太晶状态提供可浏览属性状态；Z 招式关联图鉴与招式页，不凭空创造不存在的物种形态。

`content/pokedex/entries.json` 已生成 1,440 条身份研究记录：1,025 基础物种、392 个参考包形态记录、23 个火箭队羁绊候选。这是身份编译的输入层；最终 catalog.json 已合并外观与状态至 2,384 条，按完整来源清单对账。全部记录未放行生产数据。配置见 `config/pokedex.json`，外部参考版本核对见 `research/pokedex-comparison.md`。

全国图鉴不按平台重新编号。地区图鉴是物种索引的视图，允许同一物种出现在多个地区。洗翠新增进化是独立物种，地区形态则挂在原物种下。悖谬宝可梦、究极异兽等有各自全国编号，不能笼统并入一个“神兽形态”条目。

## 形态与身份

- 物种：全国编号是展示与外部对应键，核心用稳定符号 ID。
- 地区形态：独立形态记录，挂原物种，定义独立属性、进化与来源。
- 其他稳定形态：单列保存资格及转换方式；融合形态必须保留材料个体身份，不能只生成一只额外宝可梦。
- 临时战斗形态：Mega、原始回归、究极爆发、超极巨化、其他战斗转换等按机制分别定义，各有独立图鉴条目；注册不代表能直接捕捉或永久入库。
- 外观差异：性别外观、花纹、颜色等可用变体参数表达；普通闪光不重复计为物种，不为每个随机斑点组合建一条数据库记录。
- 原创羁绊：独立 omni 命名空间，目标为火箭队 2.1 名单，23 条均有作者文档数值参考，但文档无精确版本标记，不等于已核实 2.1 完整名单。
- 首领永久 Mega：首领专用资格层，复用对应形态数据；不增加全国物种编号，不纳入玩家捕捉完成度。

每个形态分别记录：可见、可捕捉、可长期保存、可进化/转换、可参战、计入哪类完成度。不能由单个 obtainable 布尔值代替所有权限。

## 新内容边界

Z-A 及 Mega Dimension 已公开的新形态应纳入盘点范围，不能把现有参考包或旧 GBA 引擎清单当成完整最新版。官方 2026-02-27 公布 Mega Garchomp Z，证明老 Mega 清单不足。目前已导入 97 条 Mega 记录并附官方身份依据，六项数值经两份参考源核对；不得为动作制内容擅造回合制特性，转换规则需项目明确制定，其他官方回合制作品已有规定时优先核实。

Winds/Waves 官方公布 2027 年推出：本轮只追踪已公布信息，不虚构完整新世代图鉴、编号、进化或数值；发布并具备可靠数据后追加，现有稳定 ID 不重排。

## 建议的获取与完成度政策

目标是在单一存档内通过游戏流程获得所有正式物种；不要求联网、现实限时活动或双版本互换。原本通信进化可提供游戏内替代途径，版本限定可以放到不同地区或支线。是否全形态可收藏需逐形态判定，不能把战斗临时形态变成仓库个体。

幻之宝可梦建议各有支线，不靠限时礼包。传说、幻、究极异兽、悖谬等标签与剧情捕捉门槛分开：物种分类不能自动决定当前能否参战。门槛按具体获取路线配置，未完成配置不能以缺省 gate=0 进入正式内容构建。

完成度分为物种捕获、稳定形态收集、战斗形态见闻、羁绊解锁；首领专属形式可留观察档案，但不要求玩家非法获得才能 100%。临时战斗状态与未发布内容不加入普通物种捕获分母。

中文名称、来源清单和参考进化关系已补齐，后续逐种编排本项目获取地区、剧情门槛及规则；不以本身份清单替代上一阶段验证器需要的完整合法路线表。
