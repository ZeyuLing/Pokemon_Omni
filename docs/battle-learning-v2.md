# 实际策略／价值训练与自博弈（2026-10-06）

本轮已经训练模型，产生参数更新、检查点和实际对局推理；不再只是运行固定程序对战。成果是**可复现的工程学习基线**，不代表已经训练出高水平或最强宝可梦 agent。

## 当前模型与运行

- 固定赛制：Showdown 0.11.11 的第四世代 OU，尚无 Omni 自定义机制。
- 模型：每个合法候选动作使用 84 维观察／动作特征，经共享 tanh 隐藏层；策略头输出 masked softmax，价值头对合法动作隐层均值池化后输出 tanh。主模型隐藏宽度 64，总参数 **5,569**；小模型宽度 16，总参数 **1,393**。
- 训练：Python 3.12.14 / NumPy 2.3.5，CPU，手工实现且经过有限差分验证的反向传播和 Adam。无需安装新运行库，也未调用远程 GPU。
- 推理：JavaScript 加载实际训练得到的权重，数学路径与 Python 一致；模型只能接收对应选手的公开观察和己方信息。
- 数据：18 个既有人工配招生成互不重复的完整队伍组合；32 队训练、12 队开发、12 队受保护评测。不同分区共享物种与配招，只保证完整组合分开，不是新物种泛化。
- 标签：模仿目标来自当前观察的 `power` 启发式最优动作集合；价值目标来自该采集策略下的最终胜负。其值不是已校准的任意对手胜率。

主运行目录为 `build/battle-lab/reproduce-v2/`。首版、失效特征的旧实验和迭代记录保留于 `build/battle-lab/learning-v1/`，未用新输出覆盖历史。

```powershell
$battlePython = Join-Path $env:USERPROFILE '.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe'
& $battlePython tools/battle-lab/experiment.py --out build/battle-lab/my-training
```

默认完整流程约数分钟内可完成，实际时间受本机负载影响；这只是小型模型与人工阵容工程运行，不是估计训练顶尖 agent 的时间。

## 已测训练与开发结果

标准主运行包含 256 局训练对局、**11,019 条**完成对局决策样本，32 局开发数据、**1,402 条**样本。两种网络宽度、两种数据量均训练 16 个 epoch；小数据取同一训练集首批 2,815 条，属于固定嵌套子集。较大数据同时有更多优化步，不能把差异全部归因于独立样本量。

| 隐藏宽度 | 参数量 | 训练样本 | 参数更新次数 | 开发集教师动作一致率 | 开发集 value MSE |
|---:|---:|---:|---:|---:|---:|
| 16 | 1,393 | 2,815 | 352 | 97.15% | 0.5895 |
| 16 | 1,393 | 11,019 | 1,392 | 99.71% | 0.5251 |
| 64 | 5,569 | 2,815 | 352 | 98.15% | 0.5954 |
| 64 | 5,569 | 11,019 | 1,392 | 100.00% | 0.5245 |

“教师动作一致率”只要求选择教师认为并列最优的一个动作；特征中包含威力先验，且教师很简单。100% 不意味着理解全部战术或能击败高手。并列动作使用软标签，因此正确模型的交叉熵也不必为零。

主模型模仿训练后继续 **16 轮自博弈**，每轮 64 局，共 **1,024 局、36,170 条**采样决策，进行 16 次新的全批策略／价值更新。每轮使用刚刚采集这批对局的检查点，验证记录的动作概率与 value，再做一次 Monte Carlo actor-critic 更新；没有用同一旧批次反复做未校正的策略梯度。优化器每轮重建，明确记录为新 Adam 状态，不声称精确续训优化器。

开发评测每组 96 局，交换队伍和 p1/p2 位置，未参与训练的组合、固定开发种子：

| 候选策略，对手均为 power | 胜／负／截断 | 说明 |
|---|---|---|
| 未训练主模型 | 0／95／1 | 截断不计为平局或胜利 |
| 模仿学习模型 | 47／49／0 | 约相当于简单教师 |
| 再经 16 轮自博弈 | 50／46／0 | 区间仍跨 50%，不能声称可靠超越 |
| power 对 power | 48／48／0 | 本地兼容基线 |

旧 v1 特征的同类开发实验中，模仿后 50/96，自博弈后 47/96；该负结果与旧检查点保留。没有只展示有利轮次。所有数字是 `FIXTURE_NON_EMPIRICAL` 工程观测，不晋级为科研或高手水平证据。

## 正确性与修复

24 项 Node 环境／学习测试和原有 12 项合法性检查通过。训练门禁还验证了：

- 有限、非零梯度与所有预期参数组更新；BC 数值梯度误差约 `3.22e-11`。
- 1、8、32 个不同多动作样本能拟合；无更新负对照保持不变。
- 保存／重载数值一致，NumPy 与 JS 输出在 `1e-10` 容差内一致。
- 独立审计另外冻结 advantage 验证 actor-critic 梯度，最大绝对误差约 `8.39e-12`。
- 被隐藏磁力拒绝的真实采样换人也属于策略轨迹：RL 保留该动作并单独记录 `accepted:false`；BC 可以排除这种成功动作标签以外的样本。
- RL 数据一旦出现截断便拒绝更新；尚未实现截断 bootstrap，不按“只挑正常结束的局”悄悄筛选策略梯度。
- 旧特征无法区分替身／剑舞的问题已升级为 v2 效果特征并加回归测试。仍未完整表达所有特殊招式交互、临时属性、携带物和全部长期历史；没有信念网络、递归记忆或搜索。

在同一软件环境下从数据生成开始用新进程完整重跑，独立审计确认：

- 模仿学习检查点逐字节一致：`21d893bcecfdf4f23ec63a23983ed15cd57d04909b81a143f08e07178420b2ba`。
- 16 轮自博弈最终检查点逐字节一致：`2e90a7dd5a995a1221020ef267ae0134580375a632772dd3c5cb144543758386`。

这证明本机执行的可复现性；没有在其他机器、另一套 BLAS 或另一种 Python 环境完成重跑。

## 独立最终评测与证据位置

最终比较在训练及开发完成后冻结 `selection.json`，固定初始／模仿／自博弈检查点、代码、数据协议、对手、种子和对局数，由独立 evaluator 执行受保护分区。结果只用于最后报告，未反馈给特征、参数或检查点选择。

| 候选 | 对手 | 胜／负／截断 | 完成局胜率 | 完整四局块 bootstrap 95% 区间 |
|---|---|---|---:|---|
| 未训练网络 | power | 1／95／0 | 1.04% | 0–3.13% |
| 模仿学习 | power | 50／46／0 | 52.08% | 42.71–61.46% |
| 自博弈后 | power | 58／38／0 | 60.42% | 53.13–68.75% |
| 未训练网络 | random | 30／65／1 | 31.58% | 22.83–42.39% |
| 模仿学习 | random | 95／1／0 | 98.96% | 96.88–100% |
| 自博弈后 | random | 93／3／0 | 96.88% | 93.75–100% |
| power | power | 48／48／0 | 50.00% | 无块间变异，区间不报告 |

合计 672 局，671 局正常终结、1 局截断。未训练网络对 random 的区间仅来自 23 个完整块，条件于完成；全部 96 局得分上下界为 31.25–32.29%。区间只描述本合成日程，不能外推玩家群体。

自博弈对 power 的结果有有限正向信号，但没有直接 RL–BC 对战或预注册配对差异检验，且对 random 的成绩没有同时提高，**不声称自博弈模型全面优于模仿模型**。未因最终结果再选模型或调参。

主运行中的 `protected-audit.json` 和 `runs/protected-*` 保存独立结果；可提交的精简证据索引见 `research/battle-learning/2026-10-06/summary.json`。主运行 `complete.json` 只表示该工程训练流程结束，不表示“最强 agent”目标或完整研究已经完成。

大权重、优化器、完整轨迹、依赖和日志都留在被 Git 忽略的 `build/`，仓库保留可复现源代码、协议生成器、测试与精简证据。

## 数据发现与下一阶段

已查证 [Metamon 公开解析对战数据](https://huggingface.co/datasets/jakegrigsby/metamon-parsed-replays) 包含 Gen 4 OU，数据卡标为 CC-BY-NC-4.0，总文件约 28.5 GB。当前仅做来源与格式发现，未批量下载、未接入训练、未把这些权重称为从人类录像学得。其许可、版本、数据量与本项目使用范围需要在正式引入时单独记录；不把整个数据站可访问视为允许任意再分发。

下一阶段优先改进数据和对手：引入经过视角还原与许可核查的真实对战资料、强搜索基线和历史策略池，补充输入记忆与隐藏配置概率，再扩大模型与自博弈训练。现阶段继续单纯增加这个小型模型对同样人工配队的对局数，无法证明接近最强对战能力。
