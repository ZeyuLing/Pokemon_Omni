# 里程碑与验收门槛

不在未知团队规模、美术资源和硬件测试条件时承诺“几周做完全世代”。以下按风险与依赖排期；全量内容是多年级别复杂度的生产计划候选，实际工期由垂直切片的实测吞吐推算。

| 阶段 | 交付 | 必须通过的门槛 |
|---|---|---|
| R0 调研与骨架（本轮） | 来源、样本、设计与目录 | JSON 与下载哈希校验；明确未实现项 |
| R1 上游基线 | 固定提交、固定工具链的 ROM 与符号 | 可启动、上游 `make check`、内存与存档报告；确认真机测试设备 |
| R1a 可移植核心切片 | 独立核心、无画面宿主、同一任务的 GBA 绑定 | 主机/ARM 独立编译；同命令得到同任务、人物关系和奖励；跳过演出不改结果 |
| R2 双地区切片 | 丰缘与关都各一小块可玩区域 | 双向旅行、剧情旗标、复活/飞行/逃脱、存读档不损坏；中文显示 |
| R3 公平战斗核 | 从 RHH 抽离首发机制集到共享核心，观察隔离 AI | 主机/GBA 结算一致；隐藏信息/指令不变性、敌我对称、单/双打回归；无双写 |
| R4 羁绊与难度切片 | 3 个试点伙伴、4 档难度、1 条伙伴任务 | 形态事件边界、反制可用、存档还原、真机时间预算 |
| R5 首个完整地区 | 丰缘完整主线及关都扩展 | 关键剧情完整、图鉴获取可达、无进度死锁；估算全地区剩余成本 |
| R6 地区批次 | 城都/神奥，再合众至帕底亚，后续时代/DLC | 每批独立内容验收、容量复核和版本迁移，不只验收地图数量 |
| R7 长期稳定版 | 全目标内容、收藏、同版本本地对战 | 总容量、全流程、长存档、连线一致性、真机兼容矩阵 |
| R8 3D 表现切片 | 同一任务/人物/战斗接入 3D 场景 | 不修改共享剧情和结算；验证场景卸载、语义锚点和存档迁移，再扩大开放世界 |

R1a 与 RHH 基线验证可独立推进，但必须早于大量剧情制作。R8 不必等待全地区内容完成，R3 与存档契约稳定后即可做有限 3D 技术验证；不在此时预选 3D 引擎。

## 第一份可玩演示的边界

内容：一个小镇、一条路线、一个地城、一个训练师赛事入口；加一个另一地区的旅行目的地，证明跨地区系统。用已有图块，控制全新美术数量。它应展示捕获、培养、剧情、保存、旅行、规则化对战、一个羁绊任务的闭环。

这份演示必须同时能在无画面宿主运行相同剧情和战斗用例，以证明真实复用。此前不大规模重绘九个地区，避免最后才发现规则、剧情、存档被平台绑定而必须重写。

## 关键决策门槛

1. ROM 全内容估算超预算：按资产分类去重/压缩、重新分配音乐/动画成本，保留必要剧情与地图拓扑；仍超时给出具体差额与取舍，不擅自改成 PC 游戏或拆包冒充单 ROM。
2. 全收藏超标准存档预算：先压缩/调整记录结构、测冗余和真机兼容，再确定盒数与形态政策；外部仓库不作为隐含前提。
3. AI 搜索超性能预算：裁剪候选与分帧计算，保留公平观察边界；退回经过测试的启发式，不能改用偷看。
4. 上游战斗机制差异：以已固定规则为基准修复，并将差异加入测试；引用 Showdown 不等于它在所有边界都是无误的官方裁判。
5. 特定同人素材无清晰使用条件：改用可追溯替代或自绘，不让某个未授权形态阻塞玩法原型。
