## 已可操作的流程

1. 在房间醒来，下楼和妈妈交谈，电脑可领取一次伤药。
2. 前往大木研究所，听博士说明后与皮卡丘互动，确认领取 Lv.5 伙伴、五个精灵球、三瓶伤药；加入队伍并登记图鉴。
3. 穿过一号道路抵达常青市。只有草地触发野战；当前野生表为 Lv.2–4 波波、小拉达，可削弱、捕捉、逃离和替换出战伙伴。
4. 到中心恢复 HP、PP 和麻痹，和右侧火箭队交谈，确认后迎战 Lv.6 瓦斯弹；首次胜利获得 400 元并记录事件。再战由玩家交互确认，首次奖励不会重发。
5. 商店交付博士包裹，可以花钱购买精灵球和伤药。回研究所送包裹，领取一次五个精灵球奖励。商店与中心允许不同访问顺序，目标仍显示尚未完成的事件。
6. 最多六只同行伙伴，队伍左右翻页、设领队、跳转图鉴；可以保存、重启、继续，战败时全队恢复并返回家中。

新开的冒险采用以上流程。旧御三家存档仍可继续，并保留旧练习战入口，不会被静默改成皮卡丘。新建冒险有覆盖确认；需要保留旧进度时先导出。

界面已在后续修订中改用火箭队 ROM 的实际资源，参见 [来源游戏界面接入](24-source-game-interface.md)。

## 游玩与构建

`http://127.0.0.1:4173/play` 运行实际 GBA ROM。默认启动显示封面，A／B／START 进入存档菜单。图鉴直达保留在 `/play?dex`、封面 SELECT 或 `-DebugDex` 构建；`-StoryStart` 兼容参数等同默认启动。

| 场景 | 操作 |
|---|---|
| 地图 | 方向键移动，B 配合方向键跑步，A 交谈，START 菜单 |
| 战斗 | 方向键选择战斗／背包／宝可梦／逃跑，A 确认，B 返回子菜单；L 快速投球、R 快速轮换 |
| 队伍 | 左右选择伙伴，L 设为领队，A 查看该物种图鉴 |
| 浏览器 | Z=A，X=B，Enter=START，键盘 A=L、S=R，Shift=SELECT |

本次 ROM 为 27 MiB；九个场景共用图鉴，地图新增一号道路、常青市、中心、商店。尚未接入的建筑出口封闭，后续地区有开发边界提示。

## 共享逻辑与存档

`core/src/adventure.c` 管理队伍、捕获、进度事件、奖励、购物、战斗动作与结算；不读取 GBA 寄存器或地图坐标。`adapters/gba/pallet_game.c` 管理画面、格子碰撞、摄像机、输入与 SRAM。`content/pallet-town/scene.json` 绑定 GBA 地图人物和交互点。后续改写剧情时，可调整对白、人物交互和事件条件，保留队伍与图鉴接口；尚未做成完整通用剧情编辑器。

四个有语义的事件：访问中心、阻止火箭队、领取包裹、交回包裹。事件单独持久化，不用地图进入次数冒充剧情完成。再次交回包裹、再次战胜火箭队不会重复领取首次奖励。

OADV 内部数据升至 v2，仍为 132 字节，增加六人队伍的状态、经验和剧情位。OPAL 包装及双槽 OMG1 不变。加载 v1 时保留原队伍并补初始经验；浏览器导入校验与 C 核心共同接受旧版。图鉴与冒险作为同一事务保存；坏槽可回退到上一有效槽。此校验防止损坏存档，不等于完整反作弊系统。

固定上游仍为 pret/pokefirered 的 `c75f352304d529f6ba92d4f74b9cf8b5c3810788`；来源清单扩至 129 项，地图和角色资源共 3,413,376 字节。只使用资源，没有移植上游全部引擎。原始资源、生成文件、ROM、存档均不提交 Git。

## 当前战斗和美术的边界

- 运行时战斗名册仅七种：三只御三家、皮卡丘、波波、小拉达、瓦斯弹。完整图鉴目录不代表完整战斗物种已经支持。
- 仅撞击、抓、叫声、摇尾巴、电击、挣扎；两个招式槽，基础策略、HP/PP、能力等级、要害、麻痹、倒下、换人和结算。特性目前只展示名称，没有特性效果；还没有学习招式、进化、完整属性表及招式运行时。
- 经验采用开场临时规则：获胜经验为对手等级乘 12，立方升级阈值，最高 Lv.10；捕获为随 HP 变化的临时概率，野战逃离固定成功。均不能当作正式宝可梦公式或用户最终难度规则。
- 六人队满时禁止投球，不消耗球。电脑仓库、自动传送捕获物还没接入。伤药菜单当前治疗领队；战斗背包可投球，战斗恢复道具尚未实现。
- 困难／疯子 AI、馆主等级上限、超进化等机制及完整合法性政策尚未连接到这套开场战斗；没有把基础策略伪称为真人级 AI。
- 火箭队首次事件暂为交互确认开战，尚未制作主动接近和三人组演出；对应像素角色仍为普通队员。小智名字和出发对白已接入，地图主角像素仍为赤红占位，尚未替换成小智皮肤。
- 烈雀追逐、借自行车、凤王一瞥和皮卡丘关系演出尚未实现。地图、事件骨架优先，不能将简化对白称作完整动画开场。
