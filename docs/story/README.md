当前版本：2026-09-26.2。此目录是可持续更新的编剧档案；尚未接入游戏内剧情数据库。当前登记 61 位角色／伙伴、32 个正文／背景已确定／原型／未来日程节点，以及九地区与洗翠的 10 幅来源地图。

- [人物档案索引](characters.md)：已采用、候选、无名及场景提案分别标注。
- [故事世界线](worldline.md)：每个事件与参加者双向关联。
- [一周目当前背景：战争末期与冠军政治](../32-first-journey-world-premise.md)：1974 年开场、1975 年首届世界赛，含 AI 主角秘密与世界联邦制度。
- [文学正文：虹羽之约](../25-rainbow-covenant-prologue.md)、[红莲事件](../30-cinnabar-incident.md)。
- [人物年龄与日历依据](../26-master-timeline.md)、[原作选角考据](../29-prehistory-cast.md)。
- [地图审计](../28-world-atlas.md)：禁止使用旧生成世界图作地理依据。

本设定集是含核心剧透的编剧工作区，包含小智本人不知道的身份真相。不能直接作为游戏内人物图鉴或公开宣传页。未定年份、战争史、研发过程和未来结局继续留空。

## 直接查看地图与小传

```powershell
python tools/build_story_bible.py --fetch-media
python -m http.server 4180 --bind 127.0.0.1 --directory build/story-bible
```

打开 [世界地图](http://127.0.0.1:4180/)、[人物档案](http://127.0.0.1:4180/characters.html) 或 [故事世界线](http://127.0.0.1:4180/timeline.html)。阅读页独立于原有 4173 游戏预览，不改变当前存档或启动界面。服务器只绑定本机。

地图页展示真实来源地区插画，按世代分幅排列，不声称统一大陆图已经定稿。九幅来自官方网页；城都采用社区转载的《心金／魂银》原图。来源版本在每幅下标明，图片可点击放大；洗翠是神奥的历史时代层。不同地图不共享比例尺，原作现代设施不能自动放进 1943 年。本轮未补全七之岛、北上乡、蓝莓学园等扩展分幅，也没有将地图图册编译为 GBA 场景。

25 份地图／人物参考图的 URL、来源等级与 SHA-256 记录在 [媒体清单](../../research/narrative/reference-media.json)。原始图像只在本地 `build/story-bible/media/` 作为创作参考，未提交为可分发的游戏素材。主角等官方人物图有的来自后期动画；不能误称初代服装已经核对，或直接套用到前史青年人物。

## 唯一数据入口与维护顺序

| 内容 | 编辑入口 | 生成结果 |
|---|---|---|
| 世界事件、时间、角色参与、未写节点 | `content/story/worldline.json` | 世界线阅读页、文档及每个人物的已写生平 |
| 身份、年龄、动画参考、关系、人生留白 | `content/story/characters.json` | 61 份独立小传和人物检索页 |
| 地区地图版本、已知关系、未定全球坐标 | `content/story/atlas.json` | 完整目标地区图册 |
| 图片来源与哈希 | `research/narrative/reference-media.json` | 本地参考图，不自动进入游戏 |
| 修改记录 | `content/story/CHANGELOG.md` | 可追溯的设定变化记录 |

文学稿保存场景细节；登记表保存用于交叉核对的结构化事实。两者必须在同一项剧情修改中同步，不能指定一份长期不更新的稿件默默覆盖另一份。旧提纲是研究历史，不作为当前生平自动导入。

每次新增剧情：先明确事件是否已采用，再登记地点、时间、参与者及每人的实际经历；随后检查出生年、死亡状态、人物当时所知的信息、伙伴结局与地图状态。未写的阶段保留 `null`，页面和 Markdown 用空白显示。出生工作年不等于官方生日，官方角色原作的完整人生也不会自动搬进 Omni。

未来事件若只是候选，放在 `unwritten`；演员候选独立标为 `candidate`。亚当在红莲事件死亡、富士尚未被判定为泄密者、红莲神兽报告为伪造等约束已登记。主线已定 1974-04-01，旧 1967 年映射撤销；程序按实际日期与年代阶段阻止死者在当代作为活人出现，并检查事件前置关系与四年赛期。亚当的美纳斯结局没有写明，不能仅因主人死亡而判定它也死亡。

当前匿名路人与研究所助手也有各自 ID；两名共用运行时 person ID 的助手分别绑定地图实例。电脑等交互物不作为人物。喵喵有独立剧情档案，但当前原型没有独立场景实体。电影版富士与游戏富士老人不合并；大木奈奈美不能误用同名英文 Daisy 的华蓝樱花动画形象。

## 验证

```powershell
python tools/build_story_bible.py --check
python tests/story_bible.py
node tests/story-bible-browser.cjs
```

检查器覆盖 ID 唯一性、事件参与者、人物关系、出生／死亡时间、候选不得擅自获得既成经历、当前 NPC 实例覆盖、媒体哈希和生成文档漂移。语义因果、画面身份与未标日期的矛盾仍需编剧人工复核；不是自动证明所有故事逻辑正确。

本次阅读页在桌面、平板与窄屏进行实际浏览器检查；地图均加载且逐张目视检查。人物参考完成的是已有核心形象的资料归档，其他人物的参考图与全部年龄新立绘仍存在留白，不称为全人物美术完成。
