# 素材工作区

`imported/research_samples/` 已采集 RHH 固定提交的第九世代御三家样本，用于格式研究：每种包含 front.png、back.png、icon.png、normal.pal、shiny.pal。

原始来源、哈希与状态见 `research/evidence/manifest.json`；贡献者快照见 `research/evidence/rhh/CREDITS.md`。这些文件没有被宣称为本项目原创或完成逐文件权属核实。生产接入前建立具体作者与使用条件记录。

后续 `source/` 保存经审核的美术源文件，构建导出进入 build；不手改生成物，不把图片预览尺寸作为像素实际尺寸。
