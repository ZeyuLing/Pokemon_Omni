# Pokémon Omni 封面原画

2026-09-26。用户要求按本作主题重画封面，采用 `omni-cover-v3.png`，完整原画为 1536×1024。内置 **image_gen.imagegen** 生成；不是来自官方游戏的封面，也不是手绘原生 240×160 像素稿。

## 视觉意图

- 近景的现代小镇、精灵球与道路：从熟悉的宝可梦旅途起点出发。
- 远处的联盟建筑与商业高楼：旅途将触及权力、制度与财团利益。
- 中央的彩色金羽：呼应坂木寻医与神圣之羽这一既有故事起源。
- 靛蓝与金色黄昏：保留冒险的吸引力，同时带出政治悬疑的气氛。

这是象征性构图，不定义实际地图地形、城市位置、建筑坐标或新的历史事件。没有人物肖像，不泄露小智的 AI 身份，也不指定后续肉身转变的神兽。无需据此填写人物生平或世界线空白。

## GBA 接入

运行 `python tools/build_title_assets.py`，将原画完整缩至 240×160 并转为 RGB555。这里只做硬件资源转换，不在转换脚本中补画标题或场景。编译产物 `build/pallet/title.bin` 包含 76,800 字节画面和 1,536 字节的独立开始提示，总计 78,336 字节。`title.s` 引入二进制，`title.h` 提供布局常量。

开始提示使用锁定的 FireRed `PRESS START` 源像素，位置为 `(72,144)`、大小 96×8，由 ROM 控制闪烁。来源归属与文件哈希见 `../source/title-screen.json`；下载素材在 `.cache/title-source/`，不提交至 Git。原生封面与闪烁的逐像素验证由 `tests/startup-rom.cjs` 执行，实际截图在 `build/pallet/start-cover.png`。启动流程与完整验证记录见 `../../docs/38-title-and-save-menu.md`。

原画为本作生成；Pokémon 名称、精灵球等既有标识不声称为本作原创。高分辨率原画保留以供后续其他前端使用，当前实装目标是 GBA。
