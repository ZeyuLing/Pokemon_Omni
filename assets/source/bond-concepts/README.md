# Omni 羁绊概念原画

2026-09-19。本目录保存使用用户指定 imagegen 技能、内置 image_gen 工具生成的原创设计提案。没有使用 API/CLI 回退，不需要用户 API 密钥。它们不是宝可梦官方图，也不是西班牙火箭队形态的外观复原。

成功生成并接入的五张：引梦貘人、水伊布 SUI、盔甲鸟、象牙猪、神圣龙 Dun。完整 PNG 保存在 images/，原始生成文件仍保留在 Codex 默认目录。manifest.json 记录条目映射、尺寸、SHA-256 和概念稿状态；prompts.json 保存每张图片实际请求使用的完整英文提示词。

统一要求为：单只宝可梦、全身、清晰轮廓、白底、JRPG 角色原画、无文字；在保留物种辨识特征的基础上，根据当前参考属性制作 Omni 原创羁绊设计。Dun 为未知自定义物种的原创解释，不能据此推断 Dragonsden 的设计。图片尚未通过最终角色设计审定，也不是已转换的 GBA 16 色前后战斗精灵。

12 个条目尝试中有 5 个成功，7 个未取得图像。美纳斯、基拉祈、火神蛾明确返回工具 moderation_blocked（output/other），没有具体原因；九尾、雷伊布、火伊布和 Andra 叉字蝠未取得图像，早期调用未保留逐项错误详情，不能事后推定原因。见 attempts.json。没有通过更换措辞、模型或通道绕过拒绝。

可使用 tools/import_concept_art.py 将已经选定的内置工具输出复制入库。输入本地路径映射不得提交；导入器校验 PNG、已知提示词 ID，并拒绝覆盖不同内容的已有 v1 文件。内容构建校验图片哈希，禁止概念稿静默替换已有参考图。图片不会解除羁绊的研究只读标记或批准对战数据。
