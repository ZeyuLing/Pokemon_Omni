# 平台适配边界

规划三个宿主：gba、headless、open_world_3d。当前只有约定和跨平台绑定示例，无平台运行时代码。

- GBA：RHH 对接、手柄输入、图块/精灵、窗口/音频、原生存储、旅行与场景锚点绑定。
- headless：在开发机运行同一核心，注入命令/种子/内容，导出事件与状态摘要；是早期必做的可移植性验证，不等待 3D 开发。
- open_world_3d：未来引擎输入、物理、导航、地形流式加载、模型动画、镜头和 UI；引擎尚未选择。

适配层只能执行展示和平台服务，不自行结算伤害、发放任务奖励或维护第二套人物关系。尚未迁移的 RHH 功能使用显式 legacy 适配器，不能称为已经共享。平台不支持的内容必须在构建/载入时报告，不能默默跳过关键任务。
